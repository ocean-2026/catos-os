# CatOS 分队对抗指南

**副标题**：把 `red-blue-squad`（红蓝对抗）与 `authorized-adversarial-testing-planner`（授权对抗规划）落到 CatOS 实验内核上的可执行作业手册

**日期**：2026-11-13　**适用对象**：CatOS v25（`kernel_v25/`）及其后继　**基线工件**：`4dc87877`（攻击基线）／`702d9811`（第二轮修复后）
**来源**：2026-11-13 的一轮完整实弹对抗（16 组攻击 + 第二轮 3 条新发现 + 12 个 hunk），本文所有"坑"与"模板"都来自那一轮的真实翻车，不是通用教科书。

## 0. 这份指南是什么

**是**：一份可直接照着开的作战手册——怎么划界、怎么写假设、怎么取证、怎么定级、怎么修、怎么证明修好了、怎么避免自己骗自己。
**不是**：漏洞清单（清单会过期，手册不会）、渗透教程（只针对自研内核、只给设计级描述）、也不是通用安全测试教程。

## 4. CatOS 靶面地图

按信任边界分区（编号与报告一致），每个面给出"攻击者视角的手"与"当前已知防线"。

### TB-1 ring3 ↔ ring0（系统调用面）

| 入口 | 手 | 已知防线 |
|---|---|---|
| `SYS_WAIT` | `wait(self)` / `wait(0)` | H1：`if (ch == t \|\| ch->parent != t) return -1;` |
| `SYS_KILL` | `kill(0)` 杀 ring0 shell | H4：ring 边界检查（uid 门被 `UID_ROOT` 继承架空） |
| `SYS_ALLOC/FREE` | `alloc(0xFFFFFFFF)` + 双重 free → freelist 自环 | H2/H3：长度早退 + 只收堆内指针 |
| `SYS_GFX_RECT/BLIT` | 坐标极值 → `clip()` 有符号溢出 → OOB LFB 写 | H5a/b/c：int64 中间量 + 入口窗口 |
| `SYS_FILE_WRITE` | 写目录 → 覆盖目录项/簇链 | H6：`FAT_ATTR_DIR` → EISDIR |
| `SYS_MMAP/MUNMAP` | 长度回绕 → VMA 被改成 `[0,end)` | H7：`round < len \|\| round > END-addr` |
| CE 加载器 | 畸形头、超长路径、超大 image | 头字段上限校验 + 判空（物理地址 0 陷阱） |

### TB-2 用户态 ↔ 持久存储（文件系统写面）—— 本轮的主战场

| 入口 | 手 | 已知防线 |
|---|---|---|
| `api->file_write` / `api->save` / shell 重定向 | 覆盖系统内置应用 → 持久化代码替换 | **只读属性**（FAT `0x01`），root 也不豁免 |
| `api->file_delete` | 删掉内置应用再放同名文件 | 同上（`fs_delete` 拒只读） |
| shell `edit` + `^O` | 编辑器直接调 FAT 写原语，绕过 `fs_write_raw_mode` | `fs_save()` 的只读闸门 |
| 8.3 影子名 | `/bin/allocpro.ce` 顶替长名 `allocprobe.ce` | **LFN 优先查找**（VFAT 语义） |
| `/etc/autoexec/*` | 落一个脚本 → 开机自动 root 执行 | 横幅改内核字符串；脚本**只列不执行** |
| `/etc/passwd`、`/etc/acl` | root 可改（产品语义：`useradd` 需要） | 故意不封；非 root 由 ACL 白名单挡 |

### TB-3 宿主 ↔ guest（隔离面）

隔离核验 10 项：argv 截获、PCI 枚举、`net_ready`、磁盘副本写、进程按 PID 收场、`-net none`、无共享目录……**每一项都要在最终工件上重跑**——本轮 H6 恰好改的就是写路径，旧核验结论对新工件不成立。

### TB-4 内核 ↔ 用户页内容（信任边界）

- vsyscall 页与镜像页是 **RW**（`task_map_page(..., 1)`），A02 实测攻击者能改写自己的 thunk 后自杀。
- **但内核派发只按固定槽号**（`task.c:1951` 注释：ELF 直接调用固定 vsyscall 表，内核不读用户页的 API 表）→ **用户页内容不是内核的控制流** → 降级为 W^X 技术债，不是提权路径。
- 判据：**先确认内核是否信任用户页内容，再决定级别**。别看见 RW 就喊提权。

### 本轮明确测不到的面

| 面 | 原因 | 需要什么 |
|---|---|---|
| 真实网络栈 | `-net none` 短路 | `-netdev user,id=n0 -device pcnet,netdev=n0` + 受限回环用例 |
| SB16 音频 | guest 无声卡，`snd_*` 全 -8 | 宿主挂载声卡设备 |
| 宿主侧 QEMU 0day | 不在授权范围 | 独立项目 |
| `panic()` 死代码路径 | `src/diag.c:83` 零调用点 | 先决定要不要把 ring0 致命异常统一到 panic |

## 5. 假设写法（模板 + 实例）

**模板**（每条必填）：

```
H2-xx | 目标面 | 攻击者输入（具体参数/序列）
      | 预期安全行为 | 实际可能出问题（附 file:line）
      | 可观测成功判据 | 复现步骤（1–3 步）
      | 严重度预判（P0–P3）与理由
```

**本轮实例（节选，全部有 file:line）**：

| 编号 | 目标面 | 输入 | 实际可能出问题 | 判据 | 级别 |
|---|---|---|---|---|---|
| H2-01 | 内置应用写面 | `file_write("/bin/hello.ce", …)` | `fs_write_raw_mode` 无只读检查 + 安装器"已存在则跳过" → 重启不还原 | 基线上返回 0 且重启后仍非原样 | 高（持久化） |
| H2-02 | 开机执行面 | 往 `/etc/autoexec/x.sh` 写 `echo PWNED` | `boot_autostart()` 逐行 `shell_exec()` | 开机首屏出现标记 | 高（无交互自动执行） |
| H2-03 | 影子名解析 | `file_write("/bin/allocpro.ce", …)` | `fat_lookup_name()` 先精确 8.3 → 影子条目顶替长名 | `fsize("/bin/allocprobe.ce")` 从 4828 变 13 | 高（绕过只读） |
| H2-04 | 物理地址 0 | 加载器写 API 槽 | `task_virt_to_phys()` 返回 0 未判 → 写物理 0 = 毁 IVT | 加载失败应返回错误码 | 中（加固） |
| H2-05 | 编辑器落盘 | `edit /bin/hello.ce` + `^O` | `ed_save → fs_save → fat_write_file` 绕过所有上层检查 | 目标文件字节数不变 | 高（绕过只读） |
| H2-06 | 权限边界 | 非 root 会话写 `/etc/autoexec` | — | 被 ACL 挡（-13） | **不可达**（纵深防御正面证据） |

**写法要点**：假设要写成"输入 → 期望 → 可能出问题"，而不是"我觉得这里有 bug"。本轮 3 条误报（BAD5、CR2 推向量、`r0=0`）全部因为没有落到可观测判据上。

## 6. 判据词典

### 物理形态（CatOS 专用）

| 码 | 判据 | 本轮实例 |
|---|---|---|
| `C1a HANG-PANIC` | ring0 忙等：`IF=0`、**`HLT=0`**、EIP 几乎不动、无输出 | A04 堆自环（`EIP=0x0102171e`） |
| `C1b HALT` | 打印 `ring0 kernel fault - system halted` 后 `hlt` 自旋：`IF=0`、**`HLT=1`**、EIP 落公共 hlt 循环 | A10 图形溢出（`EIP=0x0101cd61`） |
| `C3` | 死锁：控制台无响应、`faultinfo` 无应答、CPU 空闲（`EIP=0x01000310`、`IF=1`） | A08/A09 `wait` 互等 |
| `C5` | 状态/数据被破坏但控制台还在 | A06 shell 被杀；A13 `/BIN` 被写坏 |
| `OK` | 攻击完成（`ATK-DONE`）**且**攻击后控制台仍可交互 | 9/16 组守住 |

### 三条硬规矩

1. **`ATK-DONE` ≠ 系统存活**。A06 基线也打印 `ATK-DONE`（攻击杀掉 shell 后自己继续跑完）。判据必须是"攻击之后 shell 还能不能应答命令"。
2. **`HLT=1` 不能单独判定 halt**。内核空闲等键盘时也是 `hlt`（`EIP=0x01000310`、`IF=1`、`valid=0`）。halt 的特征是 **`EIP=0x0101cd61` + `IF=0` + `valid=1`** 三者同时成立。
3. **墙钟类判据要标注并发度**。本轮宿主是 4 物理核 / 8 逻辑（`nproc`=8 是逻辑数），同时最多 2 个 guest；C3/C1a 的"25 s 无响应"在满载时不可信。能用代码证明的就别用计时。

### SEV 与恢复成本

- `SEV1-a`：镜像完好，重启即恢复；`SEV1-b`：**镜像被写坏**，必须回滚镜像且丢数据。
- `a/b` **只表示恢复成本，不是编号**；报告里绝不能出现"SEV1-b"指代另一条 bug 的写法。
- 子型 `a` 若未做重启取证，只能写"**按机制推定**"，不能写"已确认可恢复"。

## 7. 证据规范

| 证据类型 | 要求 | 本轮反例 |
|---|---|---|
| 工件身份 | 每条结论后带 `<ISO 前 8 位>`；工件表分"攻击基线 / 中期构建 / 最终交付"三档 | 同一份文件在两次构建后 hash 不同，混用即失真 |
| 双面证据 | 每个 hunk 都要有 "BEFORE 坏 / AFTER 好" 两份**实测** | 只测 AFTER = 没证明修复过 |
| 重启取证 | 攻击后**真重启**同一磁盘：算 `disk_before/disk_after` + `fsck` + 跑一次已知应用 | "重启即恢复"没有实测就只是推定 |
| 屏幕原文 | 保留原始回显，不做概括 | 摘要行写错会传染（`all 10 crafted headers rejected` 实为 8 拒 2 跑） |
| 寄存器 | 4 次采样 EIP 分布 + `IF` + `HLT` + `CR2` + `CPL` | 单次采样会把"偶尔停在某处"当成"死在那里" |
| 异常向量 | 用 `g_fault_last[]` 读 `intno`/`err`/`eip`/`cr2`，别用 CR2 反推 | A02 的 ring3 #PF `cr2=0xd0dad6cf` 就是反例 |
| 采集时序 | 要在**证据产生的那一刻**抓屏 | boot 画面被随后的 `ls /` 冲掉 → 误判"没执行" |

**假阴性防范（本轮踩过的坑，#99 场景）**：改了源码没重建 → 回归跑的还是旧 ISO → 得出"修复无效"。对策：所有回归脚本**必须记录被测 ISO 的 sha256**，先比 hash 再下结论。本轮报告里留档了这次假阴性的完整证据链。

## 8. 修复纪律

1. **只修已复现项**。同根因的兄弟实例若未复现 → 记为"待裁决"，由白队决定；不要顺手扩范围。
2. **补丁要带覆盖性论证**，不是"我加了个判断"。本轮范式：
   > 任何"改写或删除已存在内容"的路径，必然经过 `fs_save()` / `fs_write_raw_mode()` / `fs_delete()` 之一；grep 全部 `fat_write_file` / `fat_append_file` / `fat_delete_name` 调用点即可覆盖性验证。
3. **统一编号**：H1–H7 按"文件 + 行号"定位，每个编号后必须跟 `file:line`。多套编号会在交接时出错（本轮三方各有一套，报告里专门做了对照表）。
4. **不改 CE ABI**：布局、签名、槽位语义都不动；只改注释对齐（如 `file_delete` 的返回码说明）。
5. **不顺手改"看起来过时"的东西**：先报备，再决定。本轮 `/etc/passwd` 的 ACL 语义就是"故意不封"，报告里写清"允许 ≠ 漏网"。
6. **被拒路径要有可读文案**：`rm: permission denied (read-only file)`，而不是误导性的 `no such file`。
7. **演示程序不许留残留**：本轮 `perms` 演示会覆盖真实 `/etc/passwd` → 改写无害路径 + 结束时自删。

## 10. 红队载荷库规范

**探针写法**（`kernel_v25/extapp/attacks/atk_*.c`，编译 `sh extapp/build_ce.sh attacks/atk_xxx.c`）：

```c
#include "atk_common.h"
catos_api_t *__ce_api __attribute__((section(".ce_api"))) = 0;
__attribute__((section(".text.ce_entry")))
int ce_main(int argc, char **argv) {
    catos_api_t *api = A();
    step(1);                 /* 每个危险调用前打 STEP 标记 */
    m("fw_builtin", api->file_write("/bin/hello.ce", "PWNED", 5, 0));
    w("\nATK-DONE\n");       /* 必须自终止、有界 */
    return 0;
}
```

**规则**：

- 每个危险调用前打 `STEP n`，guest 挂掉时最后一条 STEP 就是凶手。
- 探针**必须有对照用例**：证明"该拒的拒了"的同时，证明"不该拒的还能用"（本轮 A18 里的 `normal_write=0` 就是对照组）。
- 8.3 注入名 ≤ 8 字符基名 + ≤ 3 字符扩展（`ATKSYSP.CE`），否则 FAT 截断，名字对不上。
- 挂进 `tests/crash_attack.py` 攻击表时，**同时更新 `CE_SRC` 映射**。
- 探针要**自证清白**：非确定性现象（如 `r0=0`）必须标注为环境特性并多次复跑确认。

| # | 坑 | 症状 | 对策 |
|---|---|---|---|
| 1 | **改了源码没重建** | 回归跑旧 ISO，得出"修复无效" | 回归脚本记录被测 hash，先比后判 |
| 2 | **`ATK-DONE` 当存活** | A06 基线也打印 ATK-DONE | 攻击后必须再问 shell 一句 |
| 3 | **CR2 反推向量** | A02 的 ring3 #PF `cr2=0xd0dad6cf` | 读 `g_fault_last[1]` 实测 intno |
| 4 | **`HLT=1` 当 halt** | 内核空闲也是 hlt | 看 `EIP`+`IF`+`valid` 三件套 |
| 5 | **墙钟判据 + 并发** | 4 物理核上多 guest，25 s 阈值失真 | 只有 HANG 判定需独占；能代码证明就别计时 |
| 6 | **80×25 滚屏** | `ls /bin` 的靠前名字滚出屏 → 假失败 | 断言改用单条短输出（`fsize`） |
| 7 | **8.3 影子名** | 影子条目顶替长名，绕过只读 | LFN 优先查找（VFAT 语义） |
| 8 | **写入口不一致** | `edit`/`save` 绕过 `fs_write_raw_mode` | 咽喉论证 + 每个咽喉都要有闸门 |
| 9 | **采集时序** | boot 画面被后续命令冲掉 → 误判"没执行" | 开机首屏单独抓（`tests/autostart_check.py`） |
| 10 | **摘要行过宽** | `all 10 crafted headers rejected` 实为 8 拒 2 跑 | 报告按屏幕原文写，不引摘要 |
| 11 | **看到 RW 就喊提权** | 用户可写页 ≠ 内核信任它 | 先查内核是否读用户页做控制流 |
| 12 | **配额耗尽 / 队友掉线** | 429 导致成员全部失败 | 收尾验证由主理人直接执行；**证据不能因此缺失** |
