# v2.75 变更说明（2026-11-22）

本轮目标是「完成待办 + 把 tui-preview 里的动画搬进内核」，共四件事。

## 1. help 全量汉化（待办 B1，63 项）

- `lang.c:help_zh[]` 追加 64 条：62 条命令描述 + 1 条标题 + 1 条 `keys` 描述。
- 原文与 `shell.c:cmd_help()` 的字符串**逐字对齐**，用脚本复算：`missing = 0`
  （原为 63）。
- `shell.c:281` 标题原先是 `pager_line("...")` 直出、根本没走 `trhelp()`，
  现改为 `pager_line(trhelp("CatOS v0.3 (five-pillar kernel) - commands:"))`。
- 命令名/参数/路径/CAP_/信号名按设计保持英文，只翻人类可读的描述与标题。

## 2. 中文 help 排版修复

`help_row()` 原本固定 26 列描述栏，中文是双宽字形，长描述会在屏上折行并压到
下一行命令上（截图里表现为"描述跑到命令上面"）。现在检测到描述含非 ASCII 时改排：

```
  pkg fetch NAME|URL
      下载 + 校验 + 安装签名的 .catpkg
```

英文输出路径完全不变（回归截图与改动前一致）。

## 3. `rain` —— 全屏数字雨

来源 `deliverables/tui-preview/字符雨.bat`。实现要点：

- 每列独立 `head/trail/speed/acc`，`task_sleep_ticks(2)` ≈ 20 ms 一帧；
- 头部近白 `#EAFFF2`、尾迹中绿 `#33CC44`，拖尾格用背景色清空；
- 整列滑出底部后从上方随机重生，速度/长度重新随机；
- 任意键立即退出：恢复 `PAL_FG/PAL_BG`、清屏、恢复光标。

## 4. `train` —— ASCII 蒸汽火车

来源 `deliverables/tui-preview/ascii小火车.txt`（10 行 84 列原图）。实现要点：

- 以"窗口裁剪"方式横穿屏幕，80 列文本模式与 100 列 gfx 网格都能完整跑完；
- 车头/烟两行用 `PAL_WARNING`，车身 `PAL_ACCENT`，`* CHOO CHOO *` 用 `PAL_SUCCESS`；
- 两趟后自动结束，任意键提前退出，退出不留残影。
