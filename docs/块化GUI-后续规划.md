## 2. C 阶段（v2）细化口径

**布局**
- 新增 `BLK_FREE`（枚举追加末尾，不动现有值）：子块给绝对 `x/y/w/h`，或给锚点（贴左/右/上/下、水平/垂直居中）、百分比（相对父框）、min/max、外边距。
- 解算顺序固定：父框 → 锚点/百分比 → clamp(min/max) → 落矩形，不许“边解边用”。
- 流式与自由可互嵌：FREE 里放流式子块按自然尺寸落位；流式里放 FREE 子块按声明 w/h 当固定盒。
- 拖拽/缩放只改声明几何；`moved` 收敛为 `pos_x/pos_y` 偏移，禁止再直接改写布局结果。

**交互属性化**（`blk_spec` 新增，禁 window/win_id 命名）
- `drag_mode`：0 不可拖 / 1 仅标题带 / 2 整块可拖
- `drag_bounds`：0 自由 / 1 夹在父框（含 padding）
- `resize_dir`：8 方向位掩码（L=0x1 R=0x2 T=0x4 B=0x8，角为组合），0 不可缩放
- `resize_edge`：命中带宽（默认 6px）
- `resize_min_w/h`、`resize_max_w/h`、`resize_step`（网格吸附，0=连续）
- 命中优先级改为 **resize 边缘带 > 拖拽带 > 子块命中**，并由 `gui hit` 断言固化。

**画布**
- `cv_dirty(id, x, y, w, h)` 子矩形标脏，合成只 blit 该子矩形。
- 页池 `CV_MAX_PAGES` 24 → 64，改按需分页（页表走页分配器，不加 `.bss` 静态数组）。
- 现有 7 个绘制入口不变（`b_canvas`/`gui_canvas_buffer`/`cv_pixel`/`cv_hline`/`cv_vline`/`cv_fill_rect`/`cv_blit24`），只加精度不改语义。

**验收**
- 三个样例：卡片叠放仪表盘、右侧固定侧栏 + 中央自适应、悬浮球 + 百分比定位，各一张 `-vga std` 截图。
- 像素新组 `free`（重叠只显示 z 高者、百分比定位落点正确、min/max 生效）。
- 探针 `gui free`（解算数值）、`gui cvdirty`（区域外像素差 0）、`gui interact`（8 方向 delta、clamp、bounds、子树重排节点数）。

## 3. 顺序与理由

1. **B1 先收口**：浏览器是当前唯一“能证明这套 GUI 有用”的东西，半成品不落地会一直挂在工作树里。
2. **B2 再补 TLS**：没有 HTTPS 的浏览器在 2026 年不可用，但它是内核侧问题（CA/密码套件），和 GUI 解耦，可以并行给网络线。
3. **C 在 B1 之后**：v2 的自由布局会改 damage 与命中口径，浏览器正在依赖现有布局，先让它稳定。
4. **D/E 在 C 之后**：系统化能力与 CE 兼容都需要稳定的几何/交互契约。
5. **F/G 最后**：性能与版本是收尾动作，前置功能没定完就调参是浪费。

## 4. 风险登记册

| 编号 | 风险 | 影响 | 缓解 |
|---|---|---|---|
| R1 | 真实站点 HTTPS 握手失败（`error -6`，TLS1.2，无 CA/SNI 路径） | 浏览器只能上 HTTP 站点 | 归网络线：CA 存储 + 密码套件 + SNI；GUI 线不背这个锅，验收口径先按 HTTP |
| R2 | 引入解析器/解码器使 `.bss` 增长，关键表越 `0x02000000` | 重演 E3 conc 页错误事故 | 一律池分配 + `check_link_layout.py --strict` 进门禁 |
| R3 | 画布页池 96 KB 上限 | 多画布并存分配失败 | v2 提到 64 页 + 按需分页 |
| R4 | 内核无通用 `malloc` | 第三方库集成成本高 | 固定池 bump allocator（带 reset），不引入碎片化堆 |
| R5 | 无文本折行、仅 8×16 单字号 | 网页排版保真度低、中文渲染受限 | 折行在浏览器层实现；字号扩展列入 v3 |
| R6 | 无 VSync，SVGA 全屏更新 25 Hz | 高帧率场景撕裂/抖动 | 保持每 3 tick 一帧；帧预算按 damage 面积控制 |
| R7 | 单请求阻塞（协作式让出，无抢占） | 大页或慢站会卡住整个桌面 | 只允许一个请求在飞 + 分片 pump + 状态行可中断 |
| R8 | 组件层四组件压成一个提交（`6e0ab40`） | 回溯定位粒度粗 | 后续每步一提交，已如实记在进度表 |
