## 6. 失败/搁置方向（如实记录，勿重复试）

- **野站 HTTPS**：`alert 40 handshake_failure`。本客户端仅 Offer RSA-AES128-GCM/CBC；对端（example.com/baidu）边缘优先 `ECDHE-ECDSA-CHACHA20-POLY1305`。需要新增 ChaCha20-Poly1305 与 ECDHE-ECDSA(P-256) 路径（`tls_aes.c` 已解禁）。
- **myhtml**：LICENSE 实为 LGPL-2.1-or-later，不可用；**lexbor** `.text` 161 KiB / 含 DOM 堆 460–1622 KiB，超预算。浏览器走自写瘦流式 tokenizer + `stb_image`（仅 PNG/JPEG，`.text` 24.53 KiB）。
- **裸 `mkfs.vfat` 镜像** CatOS 不认（`fat_probe()` 只扫 MBR 分区项 0x0B/0x0C）；样例盘配方见 `artifacts/gui-blocks/samples/build_gui_samples.py`。
- 抬高 `USER_IMAGE_BASE` 修 E3、压缩 GUI `.bss` 把 `acl_tab` 拉回界下：均验证为成本过高/治标，不再尝试；改为链接顺序 + `check_link_layout.py` 护栏。
