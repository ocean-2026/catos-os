### 缺陷与修法

1. **穿模（面板盖住兄弟，旧像素残留）**
   - 新增公共工具 `gui_mark_dirty_union(block *b, int x, int y, int w, int h)`
     （`compose.c`，`gui_int.h` 声明）：标脏子树 `b`，并把与矩形相交的同层兄弟子树一并标脏。
   - 各组件开面板：布局后调用 `gui_mark_dirty_union(pr, pr->x, pr->y, pr->w, pr->h)`；
     关面板：摘除前缓存根矩形，`b_remove` 后对释放矩形 ∪ 相交同层兄弟标脏。
   - 面板根 z 取 `layer_max_z(LAYER_WORK) + 1`（新查询 `layer_max_z`），不依赖挂树先序。

2. **点 z>0 行后示例块整块消失**
   - 根因：旧 `tree_detach()` 清空 `b->parent`，重挂时用已清空的父节点，`tree_attach` 直接 return，块脱离树。
   - `gui_raise_to_front()`：先缓存父节点再 detach/attach；随后 `reorder_z()` 按树先序对同层 z 全量赋 0..n-1。
   - `gui menuclick` 探针补断言：z>0 行点击后示例块仍挂到根树（`raise_live`）、可见（`raise_visible`）、中心可命中（`raise_hit`）。
     注：菜单关闭会释放菜单行，全局 `stat_blocks_live` 回落属预期，不断言全局计数相等。

3. **拖动 / 缩放坐标**
   - 拖拽目标沿父链上溯到最近 `focusable` 面板（叶子文本/行不单独拖）。
   - 拖动旧位置必须整树标脏补齐，否则拖出轨迹留残影。
   - 探针 `mouse_smoke.py`：标题带 (224,76) 拖 +120,+78；右下把手 (500,338) 外拖 20,20。
