## 1. P1-1 · D9 PE/PE32+ 基址重定位（真实崩溃缺陷）

**做了什么**：PE 装载器真实位置是 `kernel_v25/src/task.c` 的 `spawn_load_pe()`
（不是任务书写的 `src/pe.c`，该文件不存在）。在其中实现 Optional Header 的
Base Relocation 目录解析：处理 `IMAGE_REL_BASED_HIGHLOW(3)` 与 `IMAGE_REL_BASED_DIR64(10)`，
按「实际装载基址 − ImageBase」修正每个重定位项；对块大小越界、条目数超界、
RVA 超出映像一律返回负错误码；PE32+（magic 0x20b）维持拒绝。新增
`tests/mkpe_reloc.py`（现生成带 `.reloc` 的测试 PE）与 `tests/pe_reloc_probe.py`。

**怎么验的 / 实际输出**
```
$ python3 tests/pe_reloc_probe.py kernel_v25/catos.iso
PASS reloc        marker: PE-RELOC PROBE OK       # 装载基址≠ImageBase，输出正确、exit(0)
PASS badreloc     no fault, prompt back           # 畸形 PE -> err -5，无 ring0 故障
steps=2 ok=2 fail=0
```
装载路径属用户态边界，按红线复跑 E3：**2/2 PASS**；护栏 RC=0。
截图：`artifacts/v282/p1-1/p1-1-reloc.png`、`p1-1-badreloc.png`。

## 3. P1-3 · B7 text 模式中文降级（#117）

右侧搭档格留空（不画两个 `?`）；窄字符 `cp>0x7F` 也降 `?`，不再吞成空格、不吞行；
控制码/空码仍画空格（保留 #103 退格不留残影的修复）。新增 `text_note_cjk()`：

`note: 切 gfx 模式可显示中文 (switch to gfx mode to display CJK)`，`text_enter()` 复位。

## 4. P1-4 · A1.4 `.cde.conf` 外观持久化

**做了什么**：任务书写的 `desk.ce`/`extapp/desk` **不存在**（`extapp/desktop.c` 头部注明
LEGACY REFERENCE ONLY，桌面已迁到内核态 `src/gui/`）。按既有 `/etc/style` 范式新增
`src/cdeconf.c/h`：`/etc/cde.conf` 存 `theme / accent / fontsize / taskbar`（INI 风格，
hive 仍是主存储，此文件是镜像）；gui 构建时读 scheme（light→TOK_LIGHT，其余 TOK_DARK），
`theme` 命令切换时写回；文件缺失回默认。`build.sh` 三处列表加入 cdeconf.c。

**怎么验的 / 实际输出**
```
$ python3 tests/cdeconf_probe.py kernel_v25/catos.iso
PASS theme light applied (bg F6F6F4)
PASS cde.conf written with theme=light
PASS cde.conf carries live accent mirror           accent=#8250DF

PASS cde.conf survived reboot
PASS shell clean after rm cde.conf
PASS fresh volume boots to default dark            bg=0A0E14
7/7 PASS
```
**没做什么及理由**：`fontsize`、`taskbar` 只解析、未应用——块化桌面没有运行时字号状态
（8×8 位图字模）、任务栏固定下边缘；`solarized/mono` 无独立 gui token，进桌面回落
TOK_DARK。都不造假读写。
截图：`artifacts/v282/p1-4/02-light-applied.png`、`03-after-reboot.png`、`05-fresh-default.png`。

## 5. P1-5 · B5 汉化 key 查表 + 模糊回退

**做了什么**：`src/lang.c` 精确匹配优先不变；失配后先归一化（大小写折叠 / 空白压缩 /
尾部标点剥离）再比，末级用「首个英文词」松散匹配；`trs()` 未改；`help_row` 改调
`trhelp_cmd(cmd, desc)`。

**怎么验的 / 实际输出**
- 静态对照（真实 shell.c 字面量 × 真实 `help_zh[]`）：**121 条可翻译串，exact=115，
  normalised=0，loose-first-word=2，unmapped=4**（4 条是基线既有未建表：desktop/perf/gui/fpu）。
- 主机编译真实 `lang.c`（带 fs/hive 桩）：**8/8 PASS**；三变体
  `"   show   this   message   "` / `"show this message."` / `"Show This Message"` 均命中
  `显示本帮助`。
- QEMU 实机：`help` / `keys` 在 zh 下不崩溃、命令名仍英文，切 en 后英文描述可见（8/8）。
- 截图：`artifacts/v282/p1-5/01-zh-help.png`、`03-en-help.png`。

**没做什么及理由**：text 模式 VGA 字库无中文字形，实机无法从文本缓冲回读 CJK；
中文命中由静态对照 + 主机实跑保证，实机侧只验无崩溃与英文面回归。命令名消歧为最佳努力
（表项本身不带 cmd）。

## 6. P1-6 · A2.4 可拆卸性回归

**做了什么**：新增 `tests/detach_probe.py`。实测 guest 真实返回：shipped 64 MiB 镜像
`pkg list` 里确有残留 `desktop [1.0]`，`pkg info desktop` 指向 `desktop.catpkg`，
`ls /pkg` 含 `desktop.cat`；但当前 `build/pkg.list` 只打包 bc/stats/rps，desktop 属**旧镜像残留**，
块化桌面在内核态 `gui/`。

**怎么验的 / 实际输出**（15/15 PASS）
- `kernel.bin` sha256 前后一致：`49f9d652daed57eb2d90204843fedb4a5b9321319d2a5b263128eadc3e2dedb5`
- `pkg install desktop` → `installed -> /bin/desktop.ce`；Esc 退回后 `ps` 仅 1 task；
  `pkg remove desktop` → 状态回 available
- 内核 gui 进桌面 → Esc 退回 → `ps` 1 task，无残留任务
- bc 等价：install → `12 + 30 = 42` → remove → `unknown command: bc`
- 全新格式化卷 `pkg list` 仅 bc/stats/rps，无 desktop
- 截图：`artifacts/v282/p1-6/01-gui-entered.png`、`02-after-gui-shell.png`、`03-after-bc-remove.png`

**没做什么及理由**：任务书要求的 desktop CE「装→用→卸」在当前仓库没有对应新包，
只能用「残留条目 + 内核 gui + bc 等价」三层覆盖，未冒充原文流程；遗留 `desktop.ce`
是 v2.69 参考应用，未做 UI 验收。

## 7. P2-D6 · `sndinfo` PCM 诊断字段

**做了什么**：`es1371.h/c` 新增 `PERIOD/AVAIL/UNDERRUN` 诊断（-1 = 不可导出 → 显示 n/a）；
`PERIOD` 由 `DAC1_SCOUNT` 低半字（arm 时写 `frames-1`）+1 还原，`AVAIL` 由
`DAC1_FRAMECNT`（size/cnt）算并夹取；`shell.c si_pcm_block()` 在 2ch S16LE 档输出真实字段，
其余档位保持原「not exported」。

**怎么验的 / 实际输出**（QEMU `-device es1370,audiodev=snd0`）
```
es1370：Buffer size: 16384 frames; period: 16384 frames  avail: 15584 frames  underrun: n/a
sb16  ：Buffer size: 32768 frames (period/avail not exported by driver) / Underrun n/a
none  ：sndinfo: audio subsystem not initialized / no sound card
```
截图：`artifacts/v282/p2-d6/01..03`。
**没做什么**：underrun 恒 n/a（驱动无 xrun 记账，不编 0）；无真机 ES1371 可测。
