### 1.2 F2 开关

- 键位定义：`kernel_v25/include/keyboard.h:21` `#define KB_F2 0x111`；PS/2 扫描码映射在 `keyboard.c:95`（扫描码 `0x3C`）。
- 开关逻辑：`ime.c:139-144`，`ime_feed()` 收到 `KB_F2` 时翻转静态变量 `active`（`ime.c:17`）；开启时清空音节串与页码并 `ime_show()`，关闭时调用 `con_status_bar_off()` 清条。
- 状态为 `ime.c` 文件内 `static` 全局变量：`active`、`py[8]`、`py_len`、`page`、`anchor_row`（`ime.c:17-21`），readline 与编辑器共享同一实例，无每会话/每任务隔离。

### 1.3 单字拼音输入（当前为“单音节 + 精确匹配”）

- 音节缓冲：`py[8]`，长度上限 `py_len < 6`（`ime.c:18, 148`）；字母先转小写（`ime.c:146`），退格删末字母（`ime.c:152-155`）。
- 查找：`py_find()`（`ime.c:32-41`）对 `py_tab` 做**精确匹配二分查找**；表按拼音字符串排序（`pinyin.inc:6` 注释）。
- 数据表结构：`typedef struct { const char py[8]; const char *hz; } py_entry_t;`（`pinyin.inc:9`）；`hz` 为 NUL 结尾 UTF-8 串，每个汉字固定 3 字节（BMP），候选 `i` 从 `hz + 3*i` 起取（`pinyin.inc:4-7` 注释；`ime.c:106-107, 128-130`）。
- 未命中：`ime.c:77-85` 提示 `[IME] <py>: no match`。

### 1.4 候选栏：每页 9 个、`-`/`=` 翻页、数字/空格选字

- 每页上限：`#define PER_PAGE 9`（`ime.c:23`）；条缓冲 `#define BAR_MAX 200`（`ime.c:24`）。
- 翻页：`-` 上一页（`ime.c:157`），`=` 或 `]` 下一页（`ime.c:158`）；页码 `page` 在重输音节/退格/取消时归零。
- 选择：数字 `1..9` 调 `ime_commit(idx-1, out)`（`ime.c:159`）；空格选首选（`ime.c:160`）；Esc 取消（`ime.c:156`）；回车在有音节串时取消并放行（`ime.c:161`）。
- 候选构建：`ime_show()`（`ime.c:66-115`）；总字数 `total = strlen(e->hz)/3`（`ime.c:86, 125`）；页码/总页数显示在前缀（`ime.c:92-94`）。
- 宽度自适应（v2.27）：按 `con_cols()` 估算每个候选占宽（数字 + 汉字 2 格 + 空格），放不下的候选整项跳过、翻页仍可达；宽度 ≥66 列才追加 `(-/= page, esc)` 尾注（`ime.c:96-112`）。
- 上屏通道：`ime_feed(int key, char out[5])` 返回三态之一（`ime.h:16-18`）；`IME_COMMIT` 时 `out` 持有 3 字节汉字 + NUL（`ime.c:128-131`）。

### 1.5 与 shell 输入行、编辑器的集成方式

**行编辑器（`kb_readline`，`keyboard.c:394-439`）**

- 进入时取当前光标行列，`ime_set_anchor(y0)` 记录输入行（`keyboard.c:397-398`）。
- 按键循环内先经 `ime_feed(k, han)`（`keyboard.c:428`）：`IME_CONSUME` → 刷新行与候选条后继续（`keyboard.c:429, 435`）；`IME_COMMIT` → `rl_insert(han, n)` 插到光标处并重绘（`keyboard.c:430-437`）。
- 口令掩码输入 `kb_readline_masked()`（`keyboard.c:543` 起）**不经过** `ime_feed()`，即口令态无中文输入（现状行为，非缺陷）。

**内置编辑器（`shell.c` 的 `edit` 命令循环，`shell.c:2314-2389`）**

- 循环开头同样先调 `ime_feed(k, han)`：`IME_CONSUME` → `ed_redraw(); ime_refresh();`（`shell.c:2321`）；`IME_COMMIT` → `ed_insert_utf8(han)`、置修改标记、重绘、刷新候选条（`shell.c:2322-2327`）。
- 退出编辑器时 `ime_off()` 强制关闭 IME（`shell.c:2345`）；每次编辑重绘后 `ime_refresh()`（`shell.c:2388`）。
- 编辑器缓冲上限：`ED_MAX_LINES 64`、`ED_MAX_COLS 99`（`shell.c:2077-2081`），每行 99 字节 UTF-8。

### 1.6 CJK 字形来源与动态字槽

- 字形表：`font_hz.inc`，条目 `hz_glyph_t { uint16_t cp; uint8_t bits[32]; }`（`font_hz.inc:23`），16×16 1bpp，32 字节点阵；按码点排序，`render_font_hz(cp)` 二分查找（`render_font.c:130-141`），未命中返回 `0`，调用方画 `?`（`render_font.c:140`）。
- 字形规模（实测）：**6,961** 个字形，其中 6,763 个落在 U+4E00..U+9FFF 汉字区，198 个为标点/符号及其它（100 个码点 < U+4E00，98 个落在 U+FF01..U+FFE5 全角区）；码点范围 0xA4..0xFFE5；表内占用 6,961 × 34 B = **236,674 B（≈231.1 KiB）**。
- 宽字判定：`cp >= 0x80 && be->cjk && render_font_hz(cp)` 命中则按双宽单元格处理（`render.c:395, 675`）。
- text 模式动态字槽：`CON_TEXT_HZ_SLOTS 64`（`render_be.h:54`，128 个 VGA 8×16 槽 / 每字占两半）；`render.c:232-251` 维护 `gslot → cp` 映射，`be_text.c:100-128` 负责把点阵载入 VGA 字库；槽满时回退（`be_text.c:128` 附近）。
- 已在册常用标点实测：`、。，！？：“”…·` 均有字形；**制表框线 U+2500..U+257F 在册 0 个**（详见 2.3）。

### 1.7 渲染前端契约与各后端网格

- 状态栏 API：`con_status_bar(s)` / `con_status_bar_at(row, s)` / `con_status_bar_off()`（`render.h:139-144`；实现 `render.c:697-728`）。语义：保存目标行原始单元格 → 整行置反白后写入文本 → 关闭时逐格恢复；**同一时刻只有一条栏**，换行会先还原旧行（`render.c:704`）。

## 2. 差距分析

> 每条按“HEAD 现状（代码证据）→ 差距 → 对使用的影响”陈述。标注“依赖外部子系统”的项，其前置状态见第 4 章。

### 2.1 多音节长串与最大匹配

- **现状**：音节串长度上限 6（`ime.c:148`），`py_find()` 只做整串精确二分（`ime.c:32-41`）；表内 400 条均为单音节（长度分布见 1.3）；无分隔符（如 `zh'ong`）解析，无分词，无前缀候选。
- **差距**：不能输入连续拼音长串；没有最长匹配 / 分段；半音节（如 `zhon`）直接落“no match”，不给出前缀候选。
- **影响**：打词组必须逐字选；输入速度受限；与成熟拼音输入法的核心体验差距最大。

### 2.2 词组、词频排序与联想

- **现状**：表内只有单字；候选顺序是**构建期静态**的（jieba 可选 → 手工表 → GB2312 字级），运行期不记录用户选择频次；上屏后不产生后续候选联想。
- **差距**：无词组条目；无运行期词频学习；无“上一字 → 下一字/词”联想；无用户词典。
- **影响**：高频词组（如“我们”“操作系统”）需要逐字翻页选择；常用错字位置无法通过使用习惯前移。

### 2.3 标点与全角符号

- **现状**：IME 没有符号/标点模式，候选只来自 `py_tab`；字库已含 198 个标点/符号字形（`、。，！？：“”…·` 实测在册），但**框线制表符 U+2500..U+257F 在册 0 个**。
- **差距**：不能在 IME 内翻全角标点；横线分隔符没有现成字形；半角/全角切换缺失。
- **影响**：候选区横线只能靠 ASCII 字符或后端绘制（见 3.1）；中文行文的标点需另寻输入路径。

### 2.4 候选栏绘制质量与鼠标点选

- **现状**：候选条整行反白（`render.c:711` `s_attrs |= CON_ATTR_INVERSE`），首选候选无独立高亮（问题清单 #126：浮层未做首选高亮、编号徽章/间距未调）。HEAD 全仓 grep 无鼠标事件队列、无命中测试 API、无 HID 鼠标报告处理（`usb_uhci.c` 仅 HID 键盘引导协议）；`gfx24.h:52-57` 公开绘制面只有 `clear/pixel/rect/blit`，无文本测量 API。
- **差距**：候选不可点选；首选与普通候选视觉无差别；gfx24 下无法按像素做候选命中判定。
- **影响**：多候选场景只能靠键盘；并行的 v2.57 鼠标选择/剪贴板工作流落地后，候选区需能对接点选（见 3.3）。

### 2.5 光标跟随（行 / 列）

- **现状**：`anchor_row` 由调用方在进入 readline 时设置（`keyboard.c:398`），`ime_bar_row()` 把候选条放到输入行下一行，输入行在最后一行时回退上一行（`ime.c:58-64`）。**列不跟随**：候选条恒从第 0 列起绘制。编辑器循环内**不调用** `ime_set_anchor()`（全仓仅 `keyboard.c:398` 一处调用），编辑器内锚点停留在进入编辑器前的行号。
- **差距**：候选条不随输入光标列定位；编辑器多行编辑时锚点不随 `ed_cy` 移动。
- **影响**：长行/编辑器场景下候选条可能遮住新输出或落在错误行。

### 2.6 与选中 / 剪贴板集成

- **现状**：HEAD 无剪贴板、无文本选中子系统（grep `clipboard/paste/selection` 无功能命中；`shell.c` 的 `copy` 仅指文件 `cp`）；上屏路径只有 `rl_insert()` / `ed_insert_utf8()` 两条直插通道。
- **差距**：选中候选不会进入剪贴板；中键粘贴等路径与 IME 无对接。
- **影响**：依赖外部剪贴板子系统先落地（第 4 章依赖 D2）。

### 2.7 候选分页与总数显示

- **现状**：已显示“当前页/总页数”（`ime.c:92-94`）；窄列下放不下的候选被整项跳过（`ime.c:102-110`），但跳过项仍可翻页到达；未显示候选总条数（仅页数）。
- **差距**：无总字数直显；分页状态完全依赖键盘；无首尾页边界提示（越界页码在 `ime.c:87-88` 静默回第 1 页）。
- **影响**：低风险体验项，可在阶段三补全。

### 2.8 生僻字与 GB2312 外字符

- **现状**：拼音表 6,763 字全部可被 GB2312 编码（附录 A 实测）；字库为 GB2312 子集 + 198 个标点/符号；表外码点 `render_font_hz()` 返回 `0` → 画 `?`。text 模式 VGA 字库整段无中文字形（问题清单 #117，已知限制）。
- **差距**：GB2312 以外的罕用字、扩展区字符无法输入也无法显示；无 U+20000 以上扩展支持。
- **影响**：本期设计范围限定在 GB2312 常用集；扩字库属独立工具链任务。

### 2.9 繁简转换

- **现状**：字库与拼音表均为简体 GB2312 子集；无繁简映射表，无切换开关。
- **差距**：不能输出繁体；无简→繁映射数据。
- **影响**：列为远期项，不在本期三阶段内承诺。

### 2.10 其它已识别缺口

- 无模糊音（如 `z/zh`、`in/ing`）、无声调选择；
- 用户选词不持久化（无用户词典落盘）；
- 上屏通道 `out[5]` 只够 1 个三字节汉字，词组上屏需加宽；
- IME 全局单实例，readline / 编辑器 / 未来其它输入入口共享状态。

## 3. 三阶段可落地设计

### 通用约束（三阶段共同遵守）

1. **整数化**：内核 freestanding 构建为 `-m32 -O2 -std=c99 -mno-sse -mno-mmx -mno-3dnow -mno-80387`（`build.sh:26`），无 FPU/SSE 可用；**所有排序键、频次权重、页码宽度计算一律用 `int / uint16_t / uint32_t` 整数**，禁止 `float/double`、禁止浮点库调用。
2. **离线建表、提交源码**：沿用 `pinyin.inc` 模式，词表/权重由 `tools/gen_*.py` 在构建机离线生成、提交进源码树；内核运行期不依赖 Python、pypinyin、jieba 或任何字体文件。
3. **保守内存预算**：CatOS 项目内存上限 4 GiB，但内核静态表按“几十到几百 KiB”量级保守规划；新增只读表必须给出条目数 × 单条字节数的上限算式。
4. **不破坏现有三态接口语义**：`IME_PASS / IME_CONSUME / IME_COMMIT` 保持；缓冲区加宽以新增常量方式扩展，不改动返回值编码。
5. **回归不劣化**：现有手工链路（F2 → 音节 → 选字上屏 → `^S` 保存 → `cat` 回显，见 `docs/PROGRESS.md` v2.33 节）在每阶段后必须复跑通过。

### 阶段一：两行固定候选区 + 内联拼音串（UI 定案，已拍板）

#### 3.1.1 目标

把候选区从“输入行下一行的单条状态栏”改为**屏幕最底部两行**固定布局；拼音串回到输入位置（命令行/编辑器光标处）内联显示；候选条目格式固定为 `1.好 2.号 3.浩`；每页候选数按列宽自适应，**不少于现有 PER_PAGE=9**，列宽允许时可放更多；gfx24（vbe24）与 text 两种模式都正确绘制；状态栏保存/恢复语义覆盖两行（分隔行 + 候选行）。

#### 3.1.2 定案布局（实现口径，不得偏离）

- **倒数第二行**：整行横线分隔，铺满可视列。字形约束：U+2500 框线字符当前**无在册字形**（2.3），落地顺序为：
  - 方案 A（首选，不改动字体工具链）：后端用现有字符/单元格绘制——重复 ASCII `-`（`font8x8_basic` 在册）铺满，或由后端对整行做底色/反白填充形成横线；
  - 方案 B（可选跟进）：向 `tools/unifont-cjk-punct.hex` 补 U+2500 字形，经 `gen_hz_font.py` 离线重生成 `font_hz.inc`，再用框线字符绘制。
- **最后一行**：候选列表，格式 `编号.汉字`，候选之间空格分隔；编号从 1 开始；每行可放个数按 `con_cols()` 整数预算计算。
- **拼音串位置**：显示在输入处（readline 草稿行光标后 / 编辑器光标处），**不进候选区**；候选行只放分隔线与候选。
- **交互键位**：数字键选字；`Space` 选首选；`-`/`=` 或 `←`/`→` 翻页；`Esc` 取消；`F2` 开关；`Backspace` 编辑拼音串；其余键行为沿用现状。
- **双模式**：vbe24（gfx24）与 text 模式都要绘制正确；`be_gfx` / `be_vbe` 沿用同一前端单元格契约，顺带验证。

#### 3.1.3 数据结构

#### 3.1.4 算法（全部整数运算）

1. **宽度预算**：设可视列 `cols = con_cols()`。单个候选占宽：
   - 编号位数 `d = 1 + (idx >= 9) + (idx >= 99)`（1/2/3 位，整数比较）；
   - 候选宽 `w = d + 1(点) + 2(汉字) + 1(候选间空格)`；两位数候选起 `w = d + 1 + 2`，尾部空格在列宽不足时最先省略。
2. **逐候选累加**：`used += w`，`used > cols` 即停止；保底目标 9 个；若 9 个仍放不下（40 列窄网格），先省略候选间空格（`w` 减 1）再评估，仍不足则按实际可放数渲染并在阶段三适配窄屏，不得截断半个汉字。
3. **页码/总数**：沿用现有 `total = strlen(hz)/3`、`page` 计算（`ime.c:86-94`）；横线行不参与候选计数。
4. **内联拼音串**：IME 对外暴露只读组合串访问器（拟 `const char *ime_composition(void)`）；readline / 编辑器在重绘草稿行时，于光标后追加绘制该串；提交或取消后清空。
5. **两行保存/恢复**：开条目前先备份倒数第二行、最后一行原始单元格；候选行切换、关闭、后端切换、清屏时两行一并还原；text 模式恢复后触发字槽重建（沿用 `con_status_bar_off()` 的 `redraw_all()` 路径，`render.c:725`）。

### 阶段二：多音节分词 + 词组候选 + 整数字频排序

#### 3.2.1 目标

支持连续拼音长串（可含可选分隔符 `'`）；做音节切分与最长匹配；候选池合并词组与单字；按离线词频 + 运行期学习加成的**整数权重**排序；词组可整词上屏。

#### 3.2.2 数据结构（拟）

```c
/* 离线只读词组表（tools/gen_phrase.py 生成并提交） */
typedef struct {
    uint16_t phrase_off;   /* 短语串在共享字符串池的偏移（UTF-8） */
    uint16_t py_seq_off;   /* 音节序列在拼音池的偏移 */
    uint8_t  hanzi_cnt;    /* 字数（2..6） */
    uint8_t  _pad;
    uint16_t base_rank;    /* 离线内置权重带 0..4095 */
} phrase_entry_t;

/* 拼音 trie 节点（静态数组，离线生成） */
typedef struct {
    int16_t  child[26];    /* 子节点下标，-1 表示无；按字母索引 */
    uint16_t phrase_idx;   /* 该节点结束的词组条目下标，0xFFFF 表示无 */
} trie_node_t;

/* 运行期学习计数（静态，上限饱和） */
typedef struct {
    uint16_t phrase_idx;
    uint16_t learn_cnt;    /* 0..4095 饱和 */
} learn_slot_t;
```

候选运行期结构：

```c
typedef struct {
    uint8_t  kind;         /* 0=单字 1=词组 */
    uint16_t ref;          /* 单字: py_tab 下标 + 字内偏移；词组: phrase_idx */
    uint8_t  hanzi_cnt;
    uint32_t sort_key;     /* 整数排序键，见 3.2.4 */
} ime_cand_t;
```

#### 3.2.3 算法

1. **音节切分**：输入字母流先按合法音节表（现有 400 条）做左贪心最长匹配；允许 `'` 作为显式分隔符；切不出来的尾段保留为“未完成串”，不报错清空。
2. **候选收集**：
   - 词组：trie 沿切分后的音节路径匹配，命中条目入候选池；
   - 单字：沿用现有 `py_tab` 精确/前缀查询，逐音节入池；
   - 同一字面去重，保留权重更高者。
3. **整数排序键**（无浮点）：
   - 离线 `base_rank ∈ [0, 4095]`（jieba 词频分带，构建期量化为整数带）；
   - 运行期 `learn_cnt ∈ [0, 4095]`，每次该词组被上屏 `learn_cnt = min(learn_cnt + 增量, 4095)`；
   - `sort_key = ((uint32_t)base_rank << 12) | (learn_cnt & 0xFFFu)`；单字条目 `learn_cnt` 取 0；
   - 按 `sort_key` 降序；键相同时按离线内置序号升序（稳定tie-break），不引入随机或浮点。
4. **上屏通道加宽**：`ime_feed` 输出缓冲由 `out[5]` 扩为 `IME_OUT_MAX`（拟 `3*8+1 = 25` B，最多 8 个汉字 + NUL）；调用方按串长插入。
5. **退格回退**：退格先回退词组分段，再删音节字母；Esc 清空整串。

#### 3.2.4 内存预算（保守上限）

| 资产 | 预算上限 | 算式 |
|---|---:|---|
| 词组表 `phrase_entry_t` | ≤ 4,000 条 × 8 B = 32,000 B | 5 字段 + 对齐填充 ≤ 8 B/条（32-bit） |
| 共享字符串池（短语 UTF-8） | ≤ 64 KiB | 4,000 条 × 平均 16 B 估算，封顶 64 KiB |
| trie 节点 | ≤ 8,000 节点 × 54 B（26×int16 子指针 + uint16 条目号）= 432,000 B ≈ 421.9 KiB → **超限需压缩**：改为稀疏子表或仅保留首/尾字母索引，目标 ≤ 128 KiB | 落地前按实际节点数复核 |
| 学习计数表 | ≤ 256 条 × 4 B = 1,024 B | 环形槽，LRU 式淘汰 |
| 候选运行期数组 | ≤ 32 条 × 12 B = 384 B | 栈/静态 |
| **阶段二新增合计** | **词组只读表 ≤ 256 KiB（题目口径）；含 trie 与学习表整体 ≤ 320 KiB** | trie 压缩不达标则先砍词组条目数 |

## 附录 A：统计方法与口径

> 下列数字均在 HEAD `aae8640` 上实测；统计脚本为一次性 Python/grep 命令，未写入仓库。

1. **行数 / 字节数**：`wc -l`、`wc -c` 对 `src/ime.c`、`include/ime.h`、`src/pinyin.inc`、`src/font_hz.inc` 直接统计。
2. **拼音表解析**：正则 `\{"([^"]+)",\s*"([^"]*)"\},?\s*/\*\s*(\d+)\s*\*/` 逐行提取音节名、`\xXX` 转义串、注释计数；转义串按字节收集后按 UTF-8 解码；条目数 = 匹配行数；候选槽数 = 各条目解码后字数之和；去重字数 = 集合大小；最大候选 = 单条目字数最大值及对应音节；长度分布按音节字符数聚合；`>9 / >18` 与分桶按条目字数统计；GB2312 可编码性逐字尝试 `encode('gb2312')`；非三字节字符检查 `len(c.encode('utf-8')) != 3`。
3. **字形表解析**：正则提取 `{0xXXXX,` 码点；条目数 = 码点个数；汉字区计数为 U+4E00..U+9FFF，其余按 < U+4E00 与 > U+9FFF 两档统计；结构尺寸按 `uint16_t`(2 B) + `bits[32]`(32 B) = 34 B/条估算（32-bit ABI）。
4. **内存估算**：指针宽 4 B（`-m32`，`build.sh:26`）；`py_entry_t` = 8 B 数组 + 4 B 指针 = 12 B/条；UTF-8 候选池按 3 B/字；KiB 换算按 1024。
5. **后端网格**：取自 `be_text.c / be_gfx.c / be_vbe.c / be_vbe24.c` 后端描述符的 `cols/rows/pixel_w/pixel_h` 字段；vbe24 三档格子尺寸取自 `be_vbe24.c` 注释与 `v24_cw()/v24_ch()` 推导。
6. **缺失核查**：鼠标/剪贴板/分页器/`keys`/`clip`/`videomode` 等关键词在 `kernel_v25/src` 与 `include` 全量 grep，无功能命中即判定 HEAD 未落地；命中项逐一人工甄别（如 `be_vbe24.c` 的 `clip()` 为几何裁剪辅助函数，与剪贴板无关）。
7. **工具链口径**：编译器 flags 取自 `kernel_v25/build.sh:26`；字库许可与生成链路见 `font_hz.inc` 文件头与 `tools/gen_hz_font.py`；拼音表生成链路见 `tools/gen_pinyin.py` 文件头。
