# CatOS 桌面美学 · 改造清单（草案）

- 版本：草案 v1（2026-11-24），配套《桌面美学-苹果G2规格.md》使用。
- 边界：本清单**只列改造项与取值**，不在本轮改代码；旧值均从当前源码读出并标注出处。实现侧按规格 §9.1 顺序落地，每项「改 → 探针 → 回填文档 → 提交（一提交一事）」。
- 旧值基线：`gui-blocks`（`feat/gui-blocks`）；桌面图标卡取自 `gui-iso`（`feat/gui-desk`，HEAD `ab659dd`）。两线合并后以合并代码为准复核旧值。
- 标记：🟡 = 待实测；🔒 = 受渲染约束必须用近似做法；🆕 = 当前代码不存在、需新增。

## 3. 落地门禁与基线要求

1. 每项改造后重拍像素基线（截图 + 帧缓冲哈希），在 `docs/系统内测试指南.md` 登记新旧基线 sha。
2. 回归门禁全绿：vprobe 10/10、E3 2/2、F11 9/9、`check_link_layout.py --strict` RC=0、lint 0；现有 `gui idempotent/leak/dirty/drag/hit/rate/idle/menu/presence/diff/theme/reset/gesture/resize` 探针不得回归。
3. 真事件用例（P1）覆盖：单击开始按钮/菜单行/图标卡、标题带拖动（误差 ≤2 px）、右下角缩放（宽高单调增长）、双击不重复开面板、点空白不误选区；两轮 `desktop` 冒烟状态机无残留。
4. `gui console_clean` 保持 0.91% 基线；状态色/阴影改动不得引入控制台泄漏。
5. HC 令牌下所有柔化效果降级：直角、无阴影、状态靠反色/描边。
