00这份文档怎么用

一条硬规矩：原型里出现的每个视觉决定，都能在这份文档或 md v0.3 里找到对应规则号。找不到的，先当成“未支持”，不要自己发明。

本文 = 设计侧真源

回答“该不该这样画、画多少、用哪档”。数值、组成、禁用项都在这里。

md v0.3 = 转换侧真源

回答“这段 HTML 会变成什么块树”。字段、映射、诊断规则在那边，两边字段名一致。

内核头文件 = 实现侧真源

回答“到底生效没有”。文档与实现有出入时，以 `blk_spec` 定稿为准，并回写文档。

写作顺序建议：先按 §03 搭结构，再按 §04 填属性，最后逐条过 §17 自检。不要反过来从配色开始——块化 GUI 里，结构错了一切都错。

关于“假设已就绪”：文档按 cap2 全量能力写。若某次构建尚未开启某项能力，转换器会给规则号级降级诊断（例如 R-5.1-02 未支持：alpha 已忽略），原型侧把它当“待开启”，不要改成假造效果。

02画布、网格与安全区

800×600 是唯一目标分辨率。所有尺寸写整数像素，禁止 vw/vh/%/em/rem 参与布局（百分比只允许出现在 data-w="50%" 这类内置百分比属性里）。

2.1 三个保留区

区域数值规则
任务栏高 32px，贴底，宽 800浮层钳制区必须扣掉它；开始菜单不得压住它（R-2.1-01）
安全边距8px所有浮层距屏幕边 ≥ 8px；窗口贴边时该侧圆角归 0（R-2.1-02）
标题带高 28px标题带内不放操作按钮以外的内容；拖动热区默认只在这一带

2.2 间距刻度

只用 2 / 4 / 8 / 12 / 16 / 24 / 32 七档（令牌 --space-1..7）。容器内边距常用 12 或 16；列表项间 0（靠 divider 或分组圆角分隔）；分组之间 16。

2.3 网格与量化

  • 所有坐标与尺寸 8pt 对齐；例外：描边 1px、分隔线 1px、图标 16px 网格内部细节。
  • 文本基线由内核排，原型只给字号与行高，不要用 padding-top 去“顶”文字。
  • 贴边判定看量化后坐标是否精确相等；但你已经能用 data-radius 显式写 0，所以不要依赖贴边判定，直接写（R-7.4-01）。

05Alpha 半透明

层次感八成来自这里，但 alpha 也是最容易把界面做“糊”的东西。规则只有三条：分角色定值、同屏叠层 ≤ 2、文字不半透。

0.92 面板
0.72 浮层
0.55 遮罩
0.25 悬停
0.12 高亮

上图是 alpha 的五个标准档。暗色主题下 0.92/0.72/0.55 已足够表达层次；0.25 以下请只在悬停/按下态使用，大面积会露抖动颗粒。

5.1 标准档（照抄，不要自己调）

用途alphaelevation说明
普通面板 / 卡片底1.00 或 0.9210.92 只用于叠在内容之上且需要透出底色的面板
开始菜单 / 对话框0.944与任务栏重叠区域必须不透明兜底（见 §11.4）
右键菜单 / 下拉 / Tooltip0.963低于 0.92 会看不清菜单项

5.2 继承与叠层

  • alpha 继承是乘法：父 0.9 + 子 0.8 = 0.72。所以父块半透明时，子块不要再写 alpha。
  • 同一位置最多两层半透明叠加；第三层开始必须改成不透明或降为 0。
  • 文字块（TEXT/BUTTON 文本）自身 alpha 不得低于 0.85；禁用态靠父级 0.45 继承实现，不要在文字上单独写 0.45。

5.3 抖动与边缘

24bpp 出屏时按 4×4 Bayer 量化到 16 档。抖动在 0.35–0.80 区间几乎不可见；0.25 以下、纯色大面积会明显颗粒。规避方法：小面积用，或把底色改成不透明色块再用 0.12 叠高亮。

不要用 alpha 做“阴影”（那是 elevation 的事），也不要用 alpha 做“淡入淡出”以外的效果——淡入淡出属于动效，写 data-anim-props="alpha"。

阴影只表达“离地高度”，不表达“风格”。六档固定、光源固定右下、每档一张预生成贴图。你只选档，不调参。

6.1 档位分配表

档名称用在哪规则
0flat页面内容、列表行、标题带、任务栏、桌面无阴影；靠 1px 分隔线或底色差区分
1raised卡片、设置分组、内容面板常态窗口用这一档
2hover悬停中的卡片/窗口、被选中的窗口焦点窗口自动 +1 档，不必手写
3floatPopover、下拉、Tooltip、右键菜单必须叠在浮层之上，锚定后不改档
4overlay开始菜单、对话框、通知允许与任务栏重叠，但不得被任务栏盖住
5modal模态弹层（配 0.55 遮罩）同屏只允许一个；关闭前不得再开第二个

6.2 一致性与禁区

  • 同屏最多 3 档共存（常见组合：1 + 3 + 4）。出现 4 档说明层级乱。
  • 父子不叠加：子块 elevation 恒 0，阴影由父块统一画，避免“框中框”双影。
  • 贴边侧不投影：窗口贴屏幕边时，该侧阴影由内核裁掉，不要用偏移补偿。
  • HC 主题：阴影全部换成 2px 描边，elevation 值仍要写（内核据此选边框层次），但视觉上不再有投影。
  • 禁止用 box-shadow 手写阴影，禁止用多层 div 模拟。
按下态 = elevation 降 1 档 + alpha 0.18；抬起（hover）= elevation 升 1 档。抬升只允许 1 档，不要从 1 跳到 4。

7.1 四值顺序

data-radius="16 16 0 0" = TL TR BR BL（左上、右上、右下、左下）。与 CSS 的 border-radius 顺序一致，不要写成“上 下 左 右”。只写一个值 = 四角相同；写 pill = 短边一半。

档用途禁止
0贴边侧、任务栏、全出血块、组内中间项—

7.3 同心圆角（父子嵌套）

父半径 R、内边距 P，子块半径取 R − P（小于 0 取 0）。原型里直接写 data-radius="auto" 让内核推；只有需要覆盖时才手写数值。这条是“内弧穿帮”的唯一正解——子块用和父一样的 16，看起来就会像内框凸出来。

7.4 成组与贴边

  • 成组：一组紧贴的项，只有组首 TL/BL 和组尾 TR/BR 有半径，中间项全 0；组内分隔线只画 1px，不画整框（data-border-sides 只留 b 或 r）。
  • 贴边：贴屏幕边或贴父框边的一侧，该侧两角写 0。不要依赖自动判定——动态内容宽度你算不准，显式写才稳（R-7.4-01）。
  • 全出血：data-bleed 块四角 0，且不投影、不可拖。
  • 共享边只画一道：相邻两块，只让左边那块画右边框，或统一用 divider。
禁止：同一块用两套半径（外层 16、内层再套 12 且没有 padding 差）、圆形头像用 pill 以外的写法、用 overflow:hidden 裁圆角（裁剪由内核按覆盖率做）。

8.2 三条铁律

  1. 不造中间档。需要“稍小一点”就用 8 或 16，不要 12/14。内核没有这些字形，转换器会拒绝。
  2. 粗体只给标题。同屏最多 2 处 data-bold；正文加粗 = 层级失效。
  3. 数字必须 tabular。时钟、进度、内存、计数，凡是会跳变的数字都加 data-tabular，否则每秒宽窄抖动。

8.3 中文与英文混排

中文 16×16 点阵，英文 8×16。混排时英文按半角排，不要手动插空格；data-font="8" 只用于 ASCII 状态信息，中文降采样到 8px 会糊，禁止。

09折行与省略

这条解决“信息密度”：通知正文、设置项说明、错误提示都需要两行。规则是只允许有限折行，且必须给省略策略。

场景写法行高说明
通知正文data-wrap="2" data-ellipsis="char"24（8px 字号时 12）两行足够；第三行起省略
设置项说明data-wrap="2" data-ellipsis="word"24英文按词断，避免半个单词
错误提示data-wrap="3" data-ellipsis="char"24错误信息可以长一点，但别超 3 行
窗口内正文段落data-wrap="auto" data-ellipsis="char"24auto = 最多 6 行，超出省略
菜单项 / 按钮 / 标签data-wrap="0"—单行，超宽用 ellipsis，不得折行
文件名 / 路径data-wrap="0" data-ellipsis="word"—路径超长时中间省略更友好（内核按词边界）

9.1 排版细节

  • 折行宽度 = 内容框宽度（外框 − padding），不需要你算；写 data-w 即可。
  • 末行省略号由内核加，不要自己在文本里写“…”，否则会双省略。
  • CJK 不会在字中间断行；行首禁则（。，、）」等不落行首）由内核处理。你的文案里不要手动加 \n 做“假折行”，除非确实需要硬换行（如地址两行）。
  • 折行块的高度用 data-h="auto"，让内核按行数撑开；写死高度会导致文字被裁半行。
禁止无限折行：data-wrap 最大 6 或 auto；超过 6 行一律省略。桌面端没有“滚动文字块”，要读全文请放进可滚动面板。

10动效：八条缓动

动效只做“状态变化的解释”，不做装饰。时长必须是 16ms 的倍数，曲线只能选枚举，不允许自定义贝塞尔。

out-back开合、滑入：过冲一点再回落，最“现代”
out默认：快起慢收，位置变化通用
in收起、消失：慢起快收
inout同屏内挪动、重排
linear只给 alpha 淡变
in-back收起时的“先吸一下”
step离散跳变：进度、计数、光标

10.3 可中断与无障碍

  • 动画进行中新目标到来，立即接管，旧动画 settle 到目标——不会停在半路（这是内核保证，你不需要补帧）。
  • 同一个块同一时刻只能有一条动画；连点两次不要叠加 data-anim。
  • 全局 reduced_motion 开启时所有 data-anim 归 0，你的原型必须保证“无动画也正确”（只验证终点状态，不依赖中间帧）。
  • 禁止循环动画（除非画布内自绘内容）；禁止 transition / animation CSS。

11Popover 与浮层

浮层几何全部由内核算：按内容收缩 → 8px 安全边距 → 空间不足翻转 → 超 max-h 内部滚动。你只给锚点和偏好方向。

<button data-id="btn-more" data-on="click">…</button>

<c-popover data-anchor="#btn-more" data-prefer="down up right"
           data-max-h="60%" data-offset="4" data-dismiss="both">
  <div data-blk="column" data-radius="12" data-elevation="3" data-alpha="0.96">
    <button data-id="mi-new"  data-on="click">New Folder</button>
    <button data-id="mi-prop" data-on="click">Properties</button>
  </div>
</c-popover>

11.1 参数约定

项取值说明
preferdown up right left 任意顺序按序尝试，全越界则钳制到可用区
offset4–8锚点与浮层的间距；菜单用 4
max-h默认 60% 可用区超出滚动，不裁切
宽auto，最大 320内容撑开；不要写死 400
行高32菜单项统一 32，含 1px 分隔
dismissoutside / esc / both / none开始菜单用 none

11.2 子菜单桥

二级菜单必须允许“斜着移过去”不消失：内核做 400ms hover 桥（鼠标在锚点与子菜单之间的三角形区域内保持打开）。原型不要用 dismiss="outside" 去模拟，写默认 both 即可。

11.3 层与遮挡

  • Popover 恒定在 LAYER_OVERLAY 之上、Toast 之下；不要手写 data-layer 提升它。
  • 开始菜单用 overlay 层 + data-elevation="4"，且几何上不得被任务栏遮挡、不得出屏、超高可内部滚动。
  • 模态弹层（elevation 5）同屏只允许一个，且必须配 0.55 遮罩；遮罩点击 = 关闭（除声明 data-dismiss="none"）。

11.4 半透明浮层的兜底

浮层压到任务栏/窗口上时，alpha 0.96 可能透出底下的文字造成“叠字”。规则：浮层内部再垫一层不透明 RECT（role=panel），alpha 只作用于最外层圆角与投影。这是唯一允许的双层半透明写法。

禁止：自己算翻转坐标、给 Popover 写 data-place="anchor" 手动定位、嵌套超过 2 层、在浮层里放另一个浮层的触发器（改用行内展开）。

12滚动与滚动条

滚动条由内核统一画，你不允许自绘。你只需要声明“能不能滚、往哪滚、滚动条什么时候出现”。

属性取值说明
data-overflow="scroll"—开启裁剪 + 视口平移
data-scroll="y"x / y / both一次只允许一个方向为主；both 仅终端
data-scrollbar="auto"auto / always / never设置页用 auto；终端用 always
  • 轨道 8px，thumb 最小 24px，颜色取 role=border/accent，不写死灰度。
  • 滚轮一格 = 3 行 = 3×行高；不加速度、不做惯性（内核固定）。
  • 滚动条与内容之间留 4px，不遮内容。
  • 嵌套滚动最多 1 层；内层滚动到边界不传递（不做滚动链）。
  • 列表滚动时，悬停高亮跟随行，不跟 thumb。

13图标与令牌

图标是单色位图 + 角色着色，不是 SVG、不是字体图标、不是 emoji。这样做的好处是三主题、HC 全自动成立。

项规则
尺寸16×16（列表/按钮内）与 32×32（桌面/空状态/设置首图）两档，不缩放
网格16 档用 1px 描边，32 档用 2px；留 2px 内边距
着色data-tint="fg|accent|bg|border"，只改色不改形
命名用内置名（folder/gear/terminal/play/close/search/image/note），不自造
禁用多色图标、渐变图标、emoji、文字当图标、外链 SVG

13.1 令牌

颜色、圆角、阴影、间距、字体全部走令牌，原型不写十六进制。三套主题（DARK / LIGHT / HC）由内核切换，你只需要保证用的是角色而不是具体色值。

14CE 应用通道

CE 应用现在能声明真正的控件，不再只能自绘到画布。但边界很清楚：能声明块与事件，不能写像素。

14.1 可提交类型

容器：COLUMN / ROW / STACK；叶：TEXT / RECT / IMAGE / DIVIDER / SPACER / CANVAS / BUTTON / INPUT / TERM / POPOVER / ICON。不可提交：FREE（自由布局容器，内置页专用）。

14.2 事件模型

事件回调数据说明
clicktarget_id、局部 x/y按钮、菜单项；≤400ms 双击由内核合成 dblclick
focus / blurtarget_id输入框获焦时自动聚焦
inputtarget_id、UTF-8 文本、光标位每次编辑回传一次，不做逐键
wheeltarget_id、dx/dy仅声明了 scroll 的容器才收到
keykeysym、mods焦点块内有效
dismisstarget_idPopover 被点外/ESC 关闭
CE 应用的事件循环是拉取式：一帧内多次事件会排队，blk_event_poll 一次取一条。不要假设“点击必到”，要处理队列空。

14.3 仍然禁止

  • 申请帧缓冲、直接写屏幕、绕过合成器。
  • 声明 data-radius/data-alpha 之外的“自绘装饰”（阴影、圆角由内核按字段画）。
  • 用画布冒充整个窗口：CANVAS 只用于内容区（图表、游戏、预览图）。

15主题与 HC 降级

三主题不是三套皮肤，而是同一份结构 + 不同令牌。HC 的降级必须能在原型里表达，不能假装不存在。

  • 默认只写角色（fg/bg/panel/bar/accent/border/line），三主题自动成立。
  • 确实需要为 HC 单独改结构时，用 data-theme="hc" 覆盖块：HC 下强制 radius=0、border=2、阴影转描边、alpha 二值化（0 或 1）。
  • HC 下不要用 alpha 做层次（会被二值化）；改用底/边框对比。
  • 不要为 HC 单独复制一份页面；一份 HTML 三主题都能过，才算合格。
验收时的做法：同一份原型切三主题各截一张，逐项过 §17 清单。任何一套需要“临时改 CSS”的，都是结构问题。

18验收与交付

原型不是“画完就行”，要能过转换、过像素比对、过三主题。

18.1 四步流程

  1. 结构稿：只搭块树，灰阶，无颜色无阴影。转换器跑一遍，必须 rc=0 且诊断 0 阻断。
  2. 视觉稿：填角色色、elevation、alpha、radius、字号。再跑转换 + 离线预览，对照 §16 反例。
  3. 实机对照：进内核跑，按样例截 800×600 图，与离线预览逐像素比。
  4. 三主题 + 动效：切 DARK/LIGHT/HC 各截一张；动画逐帧导出 9 帧检查终点。
