# 块化 GUI v2 规格：任意矩形排版 + 溢出三态 + 拖拽/缩放属性化 + 画布子矩形脏区

> 基线：`feat/gui-blocks` `d6fbecd`。本文只描述 v2 相对 v1 的增量；v1 既有口径
> （层枚举、令牌、幂等投影、33 fps 三 tick 节流、回调只打脏位）不变。
> 代码↔文档枚举双向比对以本文件与 `include/gui/block.h` 为准。

## 1. 枚举（全部追加在末尾，不动现有值）

### 1.1 容器类型

| 值 | 名称 | 说明 |
|----|------|------|
| 11 | `BLK_FREE` | 自由布局容器：子块按绝对几何 / 锚点 / 百分比落位，不参与父容器主轴流动。 |

既有 `BLK_ROOT/COLUMN/ROW/STACK/TEXT/RECT/IMAGE/SURFACE/SPACER/DIVIDER/CANVAS` 值不变。

### 1.2 溢出三态 `overflow`

| 值 | 名称 | 语义 |
|----|------|------|
| 0 | `OVF_CLIP` | 默认。子块超出父框部分不绘制、不可命中。 |
| 1 | `OVF_VISIBLE` | 超出仍绘制、仍可命中（悬浮球 / 浮层 / 徽标）。 |
| 2 | `OVF_SCROLL` | 裁剪 + 按 `scroll_x/scroll_y` 平移内容；不改子块几何，不重排子树。 |

### 1.3 锚点位掩码 `anchor`

| 位 | 名称 | 含义 |
|----|------|------|
| 0x01 | `ANC_L` | 贴父框左边 |
| 0x02 | `ANC_R` | 贴父框右边 |
| 0x04 | `ANC_T` | 贴父框上边 |
| 0x08 | `ANC_B` | 贴父框下边 |
| 0x10 | `ANC_HCENTER` | 水平居中 |
| 0x20 | `ANC_VCENTER` | 垂直居中 |

水平 / 垂直方向独立组合；未声明的方向回退到像素 / 百分比偏移。

### 1.4 交互属性

| 字段 | 取值 | 说明 |
|------|------|------|
| `drag_mode` | `DRAG_NONE=0` / `DRAG_TITLE=1` / `DRAG_FULL=2` | 0 不可拖；1 仅标题带；2 整块可拖。兼容期 0 回落标题带（v1 默认路径）。 |
| `drag_bounds` | `BOUND_FREE=0` / `BOUND_PARENT=1` / `BOUND_SCREEN=2` | 0 不限；1 限制父框内含 padding；2 限制屏幕内。 |
| `resize_dir` | `RESIZE_L=0x1 R=0x2 T=0x4 B=0x8`，位组合；`0` 视为右下（R\|B） | 缩放方向位掩码。 |
| `resize_edge` | 默认 6 px | 边缘带宽度。 |
| `resize_min_w/h` | 默认 24 | 缩放尺寸下限。 |
| `resize_max_w/h` | 0 = 不设 | 缩放尺寸上限。 |
| `resize_step` | 0 = 连续 | 尺寸步进对齐。 |

## 2. `BLK_FREE` 约束求解规则

### 2.1 声明字段（`blk_spec` 新增）

| 字段 | 单位 / 口径 |
|------|-------------|
| `pct_x, pct_y` | 1/1000 父框偏移；0 = 未声明 |
| `pct_w, pct_h` | 1/1000 父框尺寸；0 = 未声明 |
| `px_x, px_y` | 相对锚点 / 父框的像素偏移 |
| `min_w, min_h, max_w, max_h` | 尺寸上下限；0 = 不设 |
| `m_t, m_r, m_b, m_l` | 外边距（子块与父框之间） |

### 2.2 解约束顺序（固定，不可调换）

1. **父框**：取父内容框（父框减父 padding），再扣本子块外边距 `m_*`。
2. **锚点 / 百分比**：按 `anchor` 位与 `pct_*` 落基准点；`px_*` 为二次偏移。
3. **min/max**：只约束尺寸方向，夹到 `[min, max]`；不回写坐标。
4. **落矩形**：得到最终 `x/y/w/h`。

尺寸优先级：`pct_w/pct_h` > 声明 `req_w/req_h` > 叶子自然尺寸。

### 2.3 几何口径

- **布局阶段绝不 clamp 子块坐标**：越界与否不在布局层静默改写，交给溢出策略在绘制 / 命中层对齐。
- **FREE 子块不参与父容器主轴流动**：各自按声明几何落位，不挤压兄弟。
- **互嵌**：FREE 里可放流式子块（按量得的自然尺寸落位）；流式容器（COLUMN/ROW/STACK）里可放 FREE 子块（按给定 `w/h` 当固定盒）。
- 拖拽 / 缩放产生的位置收敛为 `pos_x/pos_y` 偏移属性；`moved` 后布局保留绝对几何，跨帧不重置。

## 3. 溢出与裁剪

**一句话口径（R4 修订）：没有显式声明允许溢出的块，**几何、绘制、命中三处都绝对不能超出父块内容框**；要真溢出必须显式声明 `overflow = OVF_VISIBLE`（或子块自身 VISIBLE / 层高于父级 / moved / bleed），否则一律收缩并在裁剪处截断。**

### 3.0 三级落点（缺一不可）

| 层 | 实现 | 违反时的症状 |
|----|------|--------------|
| 几何 | `layout.c::clamp_child()`：父 `OVF_CLIP` 下，非 moved/bleed/浮层/VISIBLE 的子块矩形收缩进父内容框（含 pad） | 子块跑出窗口边框、状态行压到窗口外 |
| 像素 | `paint.c::clip_putpx()`：clip 栈非空时丢弃框外像素，文本/图标/阴影/覆盖率逐像素路径全部经此收口 | 文本越界而底色被裁（"框被切掉、字还在"） |
| 命中 | `input.c::hit_allowed()`：祖先 CLIP 时点必须落在祖先框内 | 点到框外仍触发按钮 |

历史教训：修复前 `gui_draw_text()` 直写 `gfx24_putpx()` 完全绕过裁剪栈，块终端的状态行因此被画到窗口下方——见问题清单 #222。

### 3.1 三态对齐表

| 态 | 绘制 | 命中 | damage |
|----|------|------|--------|
| `OVF_CLIP` | 越界部分不画 | 越界不可命中 | 常规脏区 |
| `OVF_VISIBLE` | 越界仍绘制 | 越界仍可命中 | 子块脏区并入父块脏区，移出后旧位置由父底色补齐防残影；再按裁剪栈只在屏内裁 |
| `OVF_SCROLL` | 裁剪 + 按 `scroll_x/scroll_y` 平移内容 | 视口外不可命中 | 同 CLIP；滚动只改偏移，不改子块几何、不重排子树 |

### 3.2 硬天花板

- **根块（屏幕）永不溢出**。
- **层高于父层的块（CHROME / OVERLAY / TOAST）不受父框裁剪**；层内仍按 z 序。
- `OVF_SCROLL` 与长列表 / 大图浏览共用同一套滚动平移机制，不另起一套。

### 3.3 探针口径（`gui bounds`）

- `OVF_CLIP`：几何可越界，但绘制被裁。
- `OVF_VISIBLE`：可越界且可命中（断言父框外点击命中该子块）。
- 根块永不越屏。
- `BLK_FREE` 默认 `OVF_CLIP`。

## 4. 拖拽 / 缩放属性化

### 4.1 命中优先级（从高到低）

1. **resize 边缘带**（沿父链就近；父块与子块重叠时父块边缘带优先）；
2. **子块自身拖拽属性**；
3. **祖先拖拽带**（标题栏托举整棵子树，v1 面板拖拽路径）；
4. **子块命中**（仅点击回调）。

### 4.2 语义约束

- 拖拽 / 缩放**只改声明几何**：FREE 下改 `x/y/w/h`；流式容器下改 `req_w/req_h` 与 `pos` 偏移；**不直接写像素**。
- 缩放 min/max / step 对齐：下限 `resize_min_w/h`（默认 24），上限 `resize_max_w/h`（0 不设），`resize_step` 对齐。
- `drag_bounds` 夹回：父框按父内容框（含 padding），屏幕按 `GFX24_W/H`。
- hover 高亮（可缩放 / 整块可拖）走令牌 accent 描边，不硬编码配色。

## 5. 画布：子矩形脏区 + 页池扩容

- 新增 `cv_dirty(id, x, y, w, h)`：只标脏该子矩形，合成层只 blit 该子矩形，**绘后清位**。
- `CV_MAX_PAGES` 由 24 提到 **64**；PFN 表在 `create` 时向帧分配器申请一页、`destroy` 归还，**不新增 `.bss` 静态大数组**；像素页按需增长到 64 页上限。
- 既有 `cv_pixel/hline/vline/fill_rect/blit24` 自动并入所触子矩形脏区。

## 6. 性能与兼容不退化

- 幂等哈希（rebuild vs 增量）在 FREE 下同样成立。
- 拖拽在 FREE 下位置不被布局重置；`gui drag` damage 面积 ≤25% 屏、帧耗时 ≤4 ms（v1 基线：首帧 2.03 ms、拖拽帧 1.09 ms）。
- 33 fps 三 tick 节流不退回；回调只打脏位、不嵌套提交。
- 既有 v1 探针子命令与三门禁（vprobe / E3 / F11）不回退。

## 7. 砍项（v2 明确不做）

- 不做旋转、alpha 混合、圆角、动画过渡。
- 不做 Grid 列宽算法（等分 / 加权列宽留后续）。
- 不做子树级滚动条控件；`OVF_SCROLL` 只提供视口平移，装饰由组件层自绘。
- 不改 CE ABI 既有槽位（0–68 不动，新槽从 69 起，append-only）。

## 8. 与 v1 差异表

| 维度 | v1 | v2 |
|------|----|----|
| 排版 | 仅 COLUMN/ROW/STACK 流式 + 绝对堆叠 | 追加 `BLK_FREE` 任意矩形：锚点 / 百分比 / min-max / 外边距 |
| 越界 | 子块永远被裁到父框内 | 三态：CLIP（默认裁）/ VISIBLE（放开绘制与命中）/ SCROLL（视口平移） |
| 手势 | `input.c` 写死标题带 24 px / 右下 12 px 句柄 | 声明式属性：`drag_mode/drag_bounds/resize_dir/edge/min/max/step` |
| 命中 | 顶层块标题带 / 句柄判定 | resize 边缘带 > 自身拖拽 > 祖先拖拽 > 子块命中 |
| 画布脏区 | 整幅缓冲 blit | 子矩形标脏、子矩形 blit、绘后清位 |
| 画布页池 | 24 页，PFN 表静态 `.bss` | 64 页，PFN 表走帧分配器，create 申请 / destroy 归还 |
| 位置保持 | 拖拽写绝对坐标 + `moved` 位 | 收敛为 `pos_x/pos_y` 偏移；`moved` 后布局保留绝对几何 |

## 9. v3 追加 ABI 清单（append-only，仅追加本节，不改动既有槽位）

> 本节为按钮图片资源 + 内核极简 SVG 光栅化子集的字段与契约追加。既有 `blk_spec` / CE
> 记录槽位偏移不变；新增字段只在结构尾部镜像，CE 侧记录槽位本轮**预留未接线**。

### 9.1 `blk_spec` / `block` 尾部追加字段

| 字段 | 类型 | 含义 | 默认 |
|------|------|------|------|
| `img` | `const char *` | 按钮图标资源路径（SVG）；`NULL`/空串 = 纯文字按钮 | `NULL` |
| `icon_sz` | `uint8_t` | 图标边长档：`0`/`16` = 16×16，`24` = 24×24；其余钳到最近档 | `0` |
| `icon_pos` | `uint8_t` | 图标位（预留变体，本轮固定左图标 + 右文字） | `0`（左） |
| `ic` | `const struct svg_icon *` | 运行时缓存句柄（**内部字段，不入 ABI**，绘制期重解析） | `0` |

### 9.2 内置极简 SVG 光栅化子集（内核侧）

- 支持图元：`rect / circle / ellipse / line / polygon / polyline / path`；`path` 仅
  `M / L / C / Q / Z`，绝对与相对坐标。
- 纯色 `fill`：`#rgb` / `#rrggbb` + 少量命名色；`stroke-width` 按 0/1px 等效折线；
  `viewBox` 等比映射。
- **明确不支持**（遇到即跳过，不报错）：`gradient / clipPath / transform / filter /
  文本 / pattern / 圆角`。
- 约束：只用整数运算；单图源 ≤64KB、输出 ≤64×64；解析失败 / 截断 / 未知元素 /
  超大源 / 超大输出一律安全回落，不留脏像素。

### 9.3 资源三级回落与缓存

1. 文件 SVG 解析成功 → 保留原色位图；
2. 文件缺失 / 解析失败 → 内置单色兜底图标（`ok / cancel / folder / file`）；
3. 两者都失败 → `NULL`，退回纯文字按钮。

- 缓存键 `(path, size, state)`；固定 8 槽、堆分配（像素/几何缓冲不进 `.bss`），槽满按
  LRU 淘汰；回落串口每条仅在真正回退时打一行：
  `GUI:img fallback path=... reason=... icon=...`（缓存命中不重复打点）。
- 排布：默认左图标 + 右文字；`label==""` 时图标水平居中；文字区让出图标位，不被覆盖。

### 9.4 CE ABI 状态

- 本轮未扩展 CE 按钮记录槽；`img / icon_sz / icon_pos` 仅内核内耗字段，由 C 侧
  `blk_spec` 填充。CE 声明语法 `img=` / `icon=` 与新记录槽位留待后续版本接线。

### 9.5 按钮图片声明语法接入（CE rec2 通道，append-only）

> 本节为 9.4 状态的后续更新；9.1–9.3 既有正文不变。内核无独立文本 `key=value`
> DSL，按钮声明入口为 CE rec2 记录通道（`ce_blk_rec2_t` + 字符串池偏移）；下述
> `img=` / `icon=` 即该通道上的对应记录字段。

- **记录槽追加（尾部 append-only，前 40B base 与既有扩展段偏移不变）**：
  | 记录字段 | 类型 | 语义 | 缺省 |
  |---|---|---|---|
  | `img_off` | `int32_t` | 字符串池内 SVG 路径偏移；`-1` = 无图片 | `-1` |
  | `icon_sz` | `uint8_t` | 图标边长档：`0`/`16` = 16×16，`24` = 24×24 | `0` |
  | `pad2_[3]` | `uint8_t[3]` | 对齐填充，不消费语义 | — |
  两处镜像同序同步：`include/ce.h`、`include/ce_abi.h`（app 侧经 `ce_app.h`
  纳入 `ce_abi.h`）。

- **落地映射（validate2 → decl_apply2）**：`img_off` 指向的池字符串复制进 pid
  文本池后挂到 `block.img`；`icon_sz` 仅在 `16`/`24` 时落地到 `block.icon_sz`，
  其余值清 `0`（走默认 16 档）；`icon_pos` 本轮固定左图标，留 `0`。

- **失败口径（与 SVG 子集「不支持就跳过」同口径）**：未知记录项、`icon_sz`
  非法值、路径为空 / 未终止 / 超长（>160 B）一律**只忽略该项**，不整批拒绝，
  其余字段照常生效；未声明时行为与接线前完全一致。

- **容量备注**：rec2 由 76B 增至 84B；声明记录区 5 页（20 KiB）下按 256 条上限
  折算余量略降，常规批量提交不受影响。
