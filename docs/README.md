## 3. 维护规则

1. **一个主题一份**：战略/计划/待办只进 `项目总纲.md`；设计只进 `设计手册.md`；历史只进 `历史记录.md`；缺陷只进 `CatOS-内核问题清单.md`；测试只进 `CatOS-测试指南.md`。
2. **不新建同义文件**：禁止再出现 `TODO-*.md`、`最终报告-*.md`、`vX.XX-变更说明.md`、`*待办.md`。
3. **一次性材料进 `archive/`**：命名 `<日期>-<主题>.md`，不进根目录。
4. **归档不复活**：需要旧结论就引用 archive 位置，不复制回根目录。
5. **改完同步状态**：改动涉及版本/阶段时，同时更新 `项目总纲.md` §0 总览。
