# CatOS 快捷键一览（v2.58）

> 本文档与内建命令 `keys`（别名 `shortcuts`）的屏幕输出**一一对应**。
> 键位描述表是内核里的**唯一数据源**：`kernel_v25/src/keys_table.c` 中的
> `keys_desc[]` 同时被键盘分发逻辑与 `keys` 命令共用。在该表中新增/扩展一行
> 绑定后，`keys` 输出与本文档对应条目自动反映，无需再手抄第二份清单。
>
> 分组顺序与屏幕显示一致：编辑 / 滚动 / 历史 / 输入法 / 控制台 / 文件。
> 标注“适用场景”说明该键在哪些界面生效；“模式限制”说明额外的上下文约束，
> 记为 `-` 表示无额外限制。

## 一、编辑（edit）

| 按键 | 作用 | 适用场景 | 模式限制 |
|---|---|---|---|
| Left / Right | 光标左右移动（UTF-8 感知，按字符而非字节移动） | 命令行 / 编辑器 | 输入法激活时同时用于候选翻页 |
| Home / End | 跳到行首 / 行尾 | 命令行 / 编辑器 | - |
| Backspace | 删除光标前一个字符 | 命令行 / 编辑器 / 输入法 | 输入法激活时删除拼音串末字母 |
| Del | 删除光标处字符 | 命令行 / 编辑器 | - |
| Ctrl+Left / Ctrl+Right | 按一个词左右移动 | 命令行 | - |
| PgUp / PgDn | 编辑器向上 / 向下翻一屏 | 编辑器 | 命令行未绑定 |

## 二、滚动（scroll）

| 按键 | 作用 | 适用场景 | 模式限制 |
|---|---|---|---|
| Ctrl+Up/Dn · Ctrl+PgUp/PgDn | 回滚 / 前进一行（方向键）或一页（PgUp/PgDn） | 控制台 | - |

## 三、历史（history）

| 按键 | 作用 | 适用场景 | 模式限制 |
|---|---|---|---|
| Up / Down | 调出历史中的上一条 / 下一条命令 | 命令行 | 编辑器内 Up / Down 为上下移动光标，不调用历史 |

## 四、输入法（IME，拼音阶段一）

| 按键 | 作用 | 适用场景 | 模式限制 |
|---|---|---|---|
| F2 | 开关拼音输入法 | 命令行 / 编辑器 | - |
| 1-9 | 按编号选择对应候选字 | 输入法激活 | 仅候选编号 1–9 可直接选择 |
| Space | 选择首选（第一个）候选 | 输入法激活 | 拼音串非空时生效 |
| `-` `=` `[` `]` | 候选上一页 / 下一页 | 输入法激活 | 方向键在拼音串非空时也可翻页 |
| Esc | 取消本次输入，清空拼音串并退出输入法 | 输入法激活 | 退出后最底两行候选区即时恢复原内容 |
| Enter | 将原始拼音串直接上屏（不选字） | 输入法激活 | 拼音串非空时生效 |

### 阶段一覆盖范围与边界

- **数据**：离线提交的 `kernel_v25/src/pinyin.inc`，共 **400 个音节**、
  **6,763 个** GB2312 子集汉字；单音节候选最多 104 个（音节 `ji`）。
- **能力**：单音节、单字输入；**暂不支持**词组/联想、模糊音、自造词与
  每会话/每任务的输入法状态隔离。
- **界面**：拼音串内联显示在输入光标处（命令行草稿行或编辑器光标后），
  不占用候选区；候选区固定在屏幕最底两行——倒数第二行为整行横线分隔，
  最后一行为 `1.好 2.号 3.浩 …` 形式的多候选，按屏幕宽度自适应尽量多排
  （至少 9 个位；窄网格下先丢候选间空格，不会把半个汉字截断）。
- **模式**：文本模式（text）与 gfx24/vbe24 帧缓冲模式均可用；退出输入法时
  最底两行按原样保存/恢复，不写坏状态栏或既有输出。
- **不生效场景**：口令掩码输入（`kb_readline_masked`）不经过输入法，
  即口令态无中文输入。

## 五、控制台（console）

| 按键 | 作用 | 适用场景 | 模式限制 |
|---|---|---|---|
| Ctrl+C | 取消当前输入行 | 命令行 | - |
| Tab | 命令 / 路径补全 | 命令行 | - |

## 六、文件（file，内建编辑器）

| 按键 | 作用 | 适用场景 | 模式限制 |
|---|---|---|---|
| Ctrl+O / Ctrl+S | 保存文件 | 编辑器 | - |
| Ctrl+X / Ctrl+Y | 退出编辑器；有改动时询问确认，`Ctrl+Y` 放弃改动退出 | 编辑器 | 确认提示下 `Ctrl+Y` 放弃 |
| Ctrl+K/U/G | 删除当前行 / 清空全文 / 显示帮助 | 编辑器 | - |

## 附：查看方式

- 在 shell 提示符下输入 `keys` 或 `shortcuts`，即按上述分组在屏幕上列出全部
  已绑定按键；同动作的兄弟键合并在同一行显示。
- 若某键在表中未出现，说明当前内核版本未为其绑定动作（解码后按普通字符
  或忽略处理）。
