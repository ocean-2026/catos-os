# CatOS v2.68 / v2.68.3 变更说明（中文输出 / 命令合并 / sudo / 输入法 / 包签名 / gfx 查询）

本轮把中文覆盖到几乎所有系统命令，收敛重复命令，修掉 sudo / 裸名 PATH /
输入法选词 / 包签名等一系列真实缺陷。v2.68.1/.2/.3 是同轮热修复：修正 RSA
验签大整数实现、sudo 参数透传、`ls --color-scale=VALUE` 的 POSIX 规格、
`strncmp_()` 精确前缀比较导致 `ls -l` 丢列，以及 `--blocks=COLS` 表头缺列。

---

## 1. 中文输出全覆盖

语言设为 `zh` 时（`/etc/hive` 的 `HKLM\System\Language`，或 `lang zh`），
以下命令输出中文：

| 命令 | 覆盖内容 |
|---|---|
| `about` | ASCII 大标严格按指定字样，正文全中文 |
| `keys` / `shortcuts` | 快捷键说明 |
| `uname` / `date` | 系统标识 / 当前 RTC（v2.68.1 补齐） |
| `mem` / `uptime` | 内存与运行时长 |
| `color` / `style` / `theme` | 配色提示 |
| `autostart` | `/etc/autostart` 脚本列出提示（仍不自动执行） |
| `caps` / `audit` | 能力位图例与审计日志 |
| `hwinfo` | 硬件属性标签 |
| 通用报错 | `permission denied` / `no such file` / `unrecognized option` 等经 `trs()` |

实现：`lang.c` 扩充 `es/en→zh` 词条，`shell.c` 约 242 处 `trs()` 调用点，
`about` 大标的中英文分支使用完全相同的 ASCII 字符（不受语言影响）。

> 注意：VGA text 后端用 128 个动态字体槽（0x80+2×slot）渲染汉字，
> QEMU 探针的 `read_screen()` 只保留 ASCII 32..126，因此**探针无法读取
> 中文文本**。中文正确性须在真机/VMware 屏幕或 gfx screendump 上目视核对，
> 不要因探针里中文断言 FAIL 就判定代码有问题。

## 2. 命令合并（收敛重复）

| 旧命令 | 新入口 | 说明 |
|---|---|---|
| `cat` | `edit -c FILE` | 打印整个文件 |
| `head` | `edit -c N FILE` | 前 N 行 |
| `tail` | `edit -c -N FILE` | 后 N 行 |
| `touch` | `edit FILE`（不存在则创建） | — |
| `rmdir` | `rm -d DIR` | — |

`cat`/`head`/`tail`/`touch`/`rmdir` 作为**退役别名**保留，执行时输出
`catos: 我们不支持此命令了，请使用: <新命令>`，不再有实际功能。
`edit` 内部仍调用 `cmd_cat/cmd_head/cmd_tail`（纯函数保留），POSIX 规格
允许 `edit -5 FILE` 这类负数位置参数。

`dir` 现在是 `ls` 的别名（同一 `cmd_ls`），两者都支持 6 种模式：
默认 / `-l` / `-t`(树) / `-lt` / `--color-scale` / `--blocks=perm,size,name`。

## 3. sudo 与裸名 PATH

- `sudo CMD [ARGS...]` 是内建命令，重入 `shell_exec()` 并把 `g_uid/g_gid`
  临时切到 `UID_ROOT`；要求 CAP_USERADM。v2.68.1 修 `sudo ls -l`：
  POSIX 校验器现在把 `sudo`/`run`/`echo` 等透传命令的第一个操作数之后
  的所有 token 当子命令参数，不再误判 `-l` 为 sudo 自己的选项。
- `PATH` 作为命令直接打印当前环境变量（`/bin` 等）。

## 4. 输入法（Shift 拼音）

- 唤出方式改为**单次孤立 Shift tap**（按下-抬起期间无其他按键），
  不再要求双击；组合键中的 Shift 不触发。
- 候选选择：`1-9` 选第 N 个、`0` 选第 10 个、`↑/↓` 循环、空格提交当前选中。
- ASCII 标点在中文模式下映射为 GB2312 全角标点（`ime_punct()`）。
- 修复中文状态下退格无效的问题。

## 5. 包签名（CPKG02 + RSA-512）

- 打包器 `tools/mkpkg.py` 升级到 `CPKG02`：204 字节头（含 64 字节签名），
  私钥 `tools/pkg_devkey.txt` 仅在宿主，内核只嵌公钥模数 `PKG_PUB_N`。
- 摘要是 header(140) + payload 的 FNV-1a64，编码为 `0x01<<56 | digest`，
  签名 `pow(m, d, n)`，验签 `pow(s, 65537, n)`。
- **v2.68.1 关键修复**：初版内核 bigint 有四重错误——`uint16_t` 累
  加溢出（64×255×255≈4.1M > 65535）、密钥大端与运算小端混用、
  模幂平方的是 base 而非 result、以及最隐蔽的：double-and-add 里
  `r<<1 | bbit` 后又 `t += a`，导致每个置位多算 +1（`1×sig` 竟等于
  `2×sig`）——任何包都验签失败、无法安装。
  重写为一致的 17×uint32_t 小端 512 位 bignum（正确的 double-and-add
  模乘：只 `t=r*2`，置位时才 `t+=a`；加正确的 square-and-multiply），
  `pkg install bc` 恢复正常。
  验证遵循"先出原型"规则：在宿主用 MinGW 编译等价 C bigint 原型，
  `1*sig==sig`、`pow(sig,65537,n)==m`（cmp=0）确认后才移植回内核。
- 文档 `docs/pkg-repo-design.md` / `SECURITY-v2.67.md` 中"CPKG01"和
  "无签名校验"的表述已过期，以 `mkpkg.py` 与 `shell.c` 为准。

## 6. gfx 模式查询与滚动

- `gfx mode`（别名 `gfx --query`）打印当前图形模式与行列数，例如
  `gfx mode: text cols=80 rows=25`。
- 命令行软换行、PgDn 逐行回滚、鼠标 sprite 压字修复继承自 v2.66。

## 7. 硬件核查结论（本轮确认）

- SATA/AHCI：未实现，当前为 IDE/ATAPI 路径。
- SMP/多核：未实现（`hwinfo cores 1`）。
- 硬盘多分区：未见完整支持，主要是 FAT32 单卷。
- 声卡：SB16 / ES1371 / ES1370，PCM 播放；`sndinfo` 的 period/avail/
  underrun、AC97 混音读取在无对应驱动时显示 `n/a`。

## 8. v2.68.1 / v2.68.2 / v2.68.3 热修复清单

1. `shell.c` bigint 重写（见 §5）——pkg 安装恢复。
2. `posix.c`：`sudo` 等透传命令的参数不再被误判为选项。
3. `posix.c`：`ls` 长选项规格补 `--color-scale=` / `--color-size=`，
   `ls -l --color-scale=size` 不再报 unrecognized option。
4. `shell.c`：`uname` / `date` 补中文 `trs()` 分支。
5. **v2.68.2：`shell.c:strncmp_()` 修复**——旧实现在 n 个字节全部相等后
   仍比较第 n+1 个字节，`strncmp_("perm,size,name","perm",4)` 返回
   `','-'\0'=44` 而非 0。这让 `ls` 的 `perm_first` 永远为假，`ls -l`
   只显示文件名、丢掉权限列和 size 列；同类精确前缀分派（`--blocks=`、
   `--color-scale=`、`gfx` 子命令）也一并失效。改为标准语义：n 字节全等
   返回 0。用 QEMU raw `read_screen()` 逐格诊断（加临时标记定位到
   `|P:0|`）确认根因后修复，与 bigint 一样遵循"先原型验证再移植"。
6. **v2.68.3：`shell.c:cmd_ls()` 的 `--blocks=` 表头缺列**——解析
   `--blocks=size,name` 时把逗号一并过滤掉，`blocks` 变成 `sizename`。
   数据行按固定 4 字符推进（`p += 4`）不受影响，但表头生成器用
   `while (*p != ',')` 按逗号分词，逗号消失后只输出第一列 → 表头缺
   `NAME`。改为解析时保留 `,`、只过滤空格。探针现验证表头为
   `SIZE NAME`（17/17 PASS）。

## 9. 版本与部署

- 构建：`cd kernel_v25 && export PATH=/c/msys64/mingw32/bin:$PATH && sh build.sh`
- 部署：`catos-v2.68.3.iso` + `kernel-v2.68.3.bin`，VMX 的 `ide1:0.fileName`
  指向 `D:\CatOs\catos-v2.68.3.iso`（VM 运行中，重启后生效）。
- 回归：`tests/v268_probe.py`，最终 **17/17 PASS**。该探针用 VGA text
  buffer 读取屏幕，`read_screen()` 只保留 ASCII 32..126，故中文命令
  （`uname`/`caps`/`hwinfo`）只断言"有输出"，视觉正确性须在 VMware
  目视核对（见 §1 注）。`about` 的 5 行 art + 描述超过 80×25 屏，改为
  断言 art 特征串 `#####` 与描述串，不做整屏逐行精确匹配。
