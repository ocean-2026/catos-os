# CatOS v2.69 变更说明（CDE P1：可拆卸图形桌面扩展）

本轮把"图形桌面环境"从设计/原型推进到**内核 ABI + 可安装扩展包**的
可运行实现。核心结论：桌面语义完全在用户态 `desktop.ce`，内核只提供
通用鼠标原语；`pkg install/remove desktop` 装卸，内核二进制前后不变。

---

## 1. 修复 CE ABI 槽 65（gotoxy）漂移

- 现象：`gotoxy(x,y)` 在 CE 程序里可能写到错误坐标。
- 根因：ABI 三处未同序——`include/ce.h` 内核镜像缺槽 65 `gotoxy`；
  更关键的是 `src/task.c:nargs[]` 只列到槽 64，槽 65 的参数个数被 C
  语言隐式补 0 → vsyscall thunk 不加载 ebx/ecx，`gotoxy(x,y)` 拿到
  上一次调用的陈旧寄存器值。
- 修复：`ce.h` 补 gotoxy 成员；`nargs[]` 补 `/*65*/2`。三处同序
  （`ce_abi.h` 原本就有 gotoxy）。
- 验证：`tests/gotoxy_v269_probe.py` 注入 `gotoprobe.ce`，清屏后
  `gotoxy(10,3)` 写标记，raw `read_screen()` 断言标记精确落在 (10,3)、
  返回值 0 → **2/2 PASS**。

## 2. 追加 3 个通用鼠标原语槽（append-only 66/67/68）

| 槽 | 签名 | 实现 |
|---|---|---|
| 66 | `int mouse_x(void)` | 薄包装 `mouse_get_state()` 的 x |
| 67 | `int mouse_y(void)` | 同上 y |
| 68 | `int mouse_buttons(void)` | 按钮掩码（1=左/2=中/4=右，沿用 MOUSE_BTN_*） |

- 三处同序同步：`include/ce_abi.h`、`include/ce.h`、
  `src/task.c`（enum + nargs[66..68]=0 + isr case）。
- 安全：只暴露绝对坐标/按钮快照，不暴露帧缓冲指针；老二进制看到 NULL，
  调用前须检查（与既有 append-only 槽一致）。
- 验证：`tests/mouse_abi_v269_probe.py` 让 CE 程序读三槽，与内核
  `mouse` 命令的读数逐项比对，全等 → **4/4 PASS**，证明 thunk 与
  `mouse_get_state()` 端到端接通。
- 环境注：本机 QEMU 无 PS/2 鼠标（`mouse` 命令 pk 恒 0），HMP/QMP 鼠标
  事件注入均不进 guest，故"移动后坐标变化"检查按环境跳过；ABI 接线由
  CE==内核断言证明，事件注入类验证留待带鼠标的 VMware/真机。

> 为什么只加 3 个而不是设计文档 §3 的全部 12 个：盘点发现参考 CDE 依赖
> 的绘图/文本/键盘能力现有 ABI 已覆盖（gfx_rect/gfx_blit/gotoxy/pollkey/
> write），唯一完全缺失的是鼠标。`gfx_text`/`key_mods`/`video_*`/`buf_*`
> 列为 P1b/P2，避免大爆炸式 ABI 膨胀。

## 3. 可拆卸桌面扩展 desktop.catpkg

- 源 `extapp/desktop.c` → `desktop.ce`（纯 CE 程序，text 后端 ASCII 窗口）。
- 全部窗口语义在 CE 侧：窗口/焦点/图标命中测试/标题栏/任务栏/事件循环，
  只用新增 mouse 槽 + gotoxy + write + pollkey。内核无任何桌面代码。
- `build/pkg.list` 增加 `desktop|1.0|detachable graphical desktop
  environment|desktop.catpkg|desktop`，复用 CPKG02 + RSA-512 签名
  （`tools/mkpkg.py` 用同一开发密钥）。
- `pkg install desktop` 验签后写 `/bin/desktop.ce`；shell 裸名查找
  （PATH=/bin）让 `desktop` 直接运行，**无需改 shell 一行代码**；
  `pkg remove desktop` 删除该文件，命令随之消失。

## 4. 生命周期实机验证

`tests/desktop_pkg_v269_probe.py`，QEMU 真实启动 → **10/10 PASS**：

1. `pkg list` 显示 desktop available，`/bin` 无 desktop.ce；
2. `pkg install desktop` → RSA-512 验签通过 → "installed desktop ->
   /bin/desktop.ce"，pkg list 标记 installed；
3. 裸名 `desktop` 运行 → 屏幕出现 Terminal/Files/About 三个 ASCII 窗口、
   左侧图标、`[Start]` 任务栏（全部由 CE 用 gotoxy 绘制）；
4. 按 `q` → "desktop: exited to text shell" 回到提示符；
5. `pkg remove desktop` → pkg list 回到 available，`desktop` 报
   "unknown command"，**内核二进制未变**。

## 5. 原型（遵循"新工具先出原型"规则）

- `deliverables/cde-prototype/cde_shell.py` —— 生命周期命令行原型
  （`--demo` 演示 install→run→remove）。
- `deliverables/cde-prototype/gfx_primitive_proto.py` —— 图形原语原型，
  宿主模拟窗口/绘制/鼠标事件循环，实跑验证焦点切换与标题栏拖拽。

## 6. 版本与部署

- 构建：`cd kernel_v25 && export PATH=/c/msys64/mingw32/bin:$PATH && sh build.sh`
- 部署：`catos-v2.69.iso` + `kernel-v2.69.bin`，VMX `ide1:0.fileName`
  指向 `D:\CatOs\catos-v2.69.iso`（VM 运行中，重启后生效）。
- 回归：gotoxy 2/2 + 鼠标 ABI 4/4 + 桌面生命周期 10/10，全部 PASS。
