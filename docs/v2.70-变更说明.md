# CatOS v2.70 变更说明（pkg 远程仓库拉包）

v2.70 把包管理从"只能读磁盘本地仓库"扩展到"可以从 HTTP 远程仓库拉签名包"，
全程复用 v2.68 的 CPKG02 + RSA-512 验签，远程包与本地包走**完全相同**的
验签路径。内核侧改动集中在 `netstack.c`（二进制安全下载）和 `shell.c`（pkg 子命令）。

> SSH-2 服务端：本轮完成宿主可行性原型（`deliverables/ssh-prototype/`，
> 系统 OpenSSH 客户端已能连入并执行命令），**尚未移植内核**；按用户确认，
> 内核 SSH 另起分期实现。详见该目录 README 与原型源码。

## 1. 新增命令

```
pkg repo [http://IP[:port]/dir]   # 无参查看；有参设置远程仓库 base URL（存 hive，重启保留）
pkg update                        # GET <repo>/PKGS.TXT 覆盖本地 /pkg/PKGS.TXT
pkg fetch NAME                    # 查索引文件名 -> GET <repo>/<file> -> 验签 -> 装 /bin/<cmd>.ce
pkg fetch http://IP[:port]/x.catpkg  # 显式 URL 直拉（不受索引限制）
```

`pkg list/info/install/remove` 语义不变；`help` 增加四行说明。

## 2. 网络层：二进制安全下载

- `netstack.c`：把 `net_http_get()` 的请求/收包/响应解析核心抽成
  `static int http_fetch(url, uint8_t* out, max)`，返回精确字节数、不追加 NUL。
  - `net_http_get()` 保留文本语义（`curl` 用）：`max-1` 截断 + NUL 结尾。
  - **新增 `net_http_download()`**：原样拷贝 body、零字节保留，供 `.catpkg` 使用。
- `tcp.rcv_buf` 从 4096 扩到 20480：整包（4–16 KiB payload + HTTP 头）可一次性接收，
  不再因缓冲满提前截断。
- `net.h` 增加 `net_http_download()` 声明与错误码说明。

为什么不能直接用 `net_http_get()`：它是 `char* out` + NUL 结尾，且按 Content-Length
截断到 `max-1`；`.catpkg` 头部/签名/payload 含大量 0 字节，会被当成字符串截断。

## 3. 验签零分叉

`shell.c` 把原来 `cmd_pkg_install()` 里的 magic/length 校验、`pkg_verify()`、写盘
抽成 `static void pkg_install_payload(int rd)`：
- 本地 `pkg install NAME`：从 `/pkg/<file>` 读到 `pkg_payload` → 调该函数。
- 远程 `pkg fetch ...`：`net_http_download()` 读到 `pkg_payload` → 调同一函数。

因此远程包**不可能绕过验签**：篡改 payload 任一字节，FNV-1a64 摘要改变，
RSA-512 `pow(sig,65537,n)` 与编码摘要不等 → "SIGNATURE VERIFICATION FAILED - install refused"。

## 4. 配置持久化与边界

- 仓库 URL 存在 hive `HKLM\Software\CatOS\Net\PkgRepo`（`hive_set_sz` + `hive_save`），
  与 v2.67 起的配置体系统一。
- URL 只接受 `http://` 前缀；https 未实现（内核无 TLS）。
- 传输不加密：公开软件包的机密性无意义，完整性/来源由签名保证（apt/npm 同理）。
- 私钥 `tools/pkg_devkey.txt` 仅在宿主签名时使用，不进内核。

## 6. 已知问题 / 边界

- 探针里 `bc.catpkg` 这个示例包在当前内核上**本来就运行崩溃**（page fault
  `eip=0x0200030e cr2=0x00000038`，v2.68.3 旧 ISO 同样如此），与远程拉包无关；
  因此"远程装完能运行"改用 `desktop` 包验证。该包本身的问题留待排查 CE 二进制兼容性。
- 本机 QEMU 无 PS/2 鼠标（鼠标包计数恒 0）；远程装的桌面用键盘 `q` 退出验证。
- 远程仓库需宿主/局域网有 HTTP 服务；包体大小受 `PKG_BUF_MAX`（16 KiB）与
  `tcp.rcv_buf`（20 KiB）限制，更大的包需后续做流式落盘。

## 7. 版本与部署

- 构建：`cd kernel_v25 && export PATH=/c/msys64/mingw32/bin:$PATH && sh build.sh`
- 部署：`catos-v2.70.iso` + `kernel-v2.70.bin`，VMX `ide1:0.fileName` 指向新 ISO
  （VM 运行中，重启后生效）。
- 新增文件：`tests/pkg_remote_v270_probe.py`、`deliverables/pkg-remote-prototype/`、
  `deliverables/ssh-prototype/`。
