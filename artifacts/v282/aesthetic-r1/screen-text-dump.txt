    Kernel       : interrupts + paging + tasks
                   ring3 CE apps via int 0x80, uid perms

    Input        : PS/2 keyboard (IRQ-driven)

    Version      : CatOS v2.82

===== 04-help =====
  format                    erase the FAT32 volume (y/n confirm)
  fsck                      check FAT mirror + scan dir tree; --purge wipes bad
entries
  mount                     list the mount table
  mount <1..4|hd0pN> DIR    bind a FAT32 partition to an empty dir
  umount DIR                detach the partition bound to DIR
  df                        per-mountpoint volume usage
  faultinfo                 show the last fatal fault (vector, CR2, PF bits)
  crashlog                  show the saved panic record (crashlog --full for raw
)
  edit FILE                 nano-style full-screen editor; -c/-c N/-c -N prints
   (arrows move, ^O save, ^X exit, ^K del line, ^U clear)
