## 4. P2 两项

### 4.1 `vbe_pan_wc_probe`（D7 pan/WC 逐像素）
- 命令：`python3 tests/vbe_pan_wc_probe.py kernel_v25/catos.iso`
- 真实输出（`vbe_pan_wc.log`）：
  ```
  swatch pixel at (8,24): (255, 255, 0) (800x600)
  PASS vbe-pe  yellow swatch: readback OK, pan n/a
  steps=1 ok=1 fail=0
  ```
- 颜色语义核对：探针判定逻辑 `r>150 && g>150 && b<100` → 黄 `0xFFFF00` = 回读 OK、pan 在当前后端 n/a；红 `0xFF0000`=像素不一致，绿 `0x00FF00`=回读+pan 均 OK。实测黄色，**语义自洽**，且探针打印了 `pan n/a` 原因（未把 n/a 静默当 PASS）。
- 判定：**PASS 1/1**。备注：QEMU Bochs dispi 路径 `pan_rows=0`，pan 不可测记 n/a，与文档“只验证不改行为”边界一致。

### 4.2 `p2_d6_sndinfo_probe`（D6 PCM 诊断字段，三档）
- 命令：`python3 tests/p2_d6_sndinfo_probe.py es1370|sb16|none`
- 真实输出：
  - **es1370**（`sndinfo-es1370.log`）：
    - 空闲：`Buffer size: 16384 frames; period: 0 frames avail: 0 frames underrun: n/a`
    - `sndtest`：`playing 440 Hz for 800 ms ... SNDTEST PASS`
    - 播音后：`Buffer size: 16384 frames; period: 16384 frames avail: 15348 frames underrun: n/a`
  - **sb16**（`sndinfo-sb16.log`）：`Buffer size: 32768 frames (period/avail not exported by driver) Underrun count: n/a`，两阶段一致。
  - **none**（`sndinfo-none.log`）：`sndinfo: audio subsystem not initialized / no sound card`。
- 真实性核对（对照 `docs/v282/p2-d6-sndinfo-notes.md` 与 `src/es1371.c`）：
  - `PERIOD` 由 `DAC1_SCOUNT` 低半字 +1 还原；`AVAIL = size - cnt + 1` 并夹取；`UNDERRUN` 恒 -1（n/a）。源码路径为寄存器实读，**非编造 0/常数**。
  - 判定：**PASS（三档口径正确）**；**WARN-3**：文档样例 `avail: 15584`，本次实测 `avail: 15348`。`avail` 是随 DMA 消费计数实时变化的量，两次采样不同属正常；但文档把 15584 写成确定值易被误读为固定字段，建议标注为“采样时刻样例”。`period: 16384` 与文档一致。
  - sb16 / none 文案与文档一致；underrun 恒 n/a，未编 0。
